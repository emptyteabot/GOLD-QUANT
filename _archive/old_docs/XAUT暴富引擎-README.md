# XAUT暴富引擎 - 黄金军团多智能体系统

## 🎯 系统概述

这是一个基于深度研究报告构建的**价值千万级**XAUT激进套利系统，采用多智能体架构，专门捕捉加密市场暴跌中的"插针"机会，实现暴富效应。

### 核心策略
- **暴跌反弹**: 利用清算级联造成的价格脱锚
- **阶梯接针**: 分批建仓，降低持仓成本
- **延迟套利**: 跨交易所价格滞后套利
- **动态风控**: ATR止损、USDT脱锚监控、熔断机制

### 四大智能体
1. **哨兵** - 监控清算流、巨鲸异动、宏观新闻
2. **分析师** - 计算公允价值、Z-Score、订单簿失衡
3. **狙击手** - 执行阶梯挂单、追踪止盈、延迟套利
4. **执政官** - 风险管理、资金分配、熔断保护

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install redis ccxt numpy aiohttp requests python-dotenv
```

### 2. 启动Redis

```bash

redis-server

# Linux/Mac
redis-server
```

### 3. 配置环境变量

复制 `.env.template` 为 `.env`，填入配置：

```bash
cp .env.template .env
```

**必填项**：
- `FEISHU_WEBHOOK_URL`: 飞书机器人Webhook（接收交易信号）
- `OKX_API_KEY/SECRET/PASSWORD`: OKX交易所API（实盘交易）
- `TOTAL_CAPITAL`: 总资金（USDT）

### 4. 启动系统

```bash
python XAUT暴富引擎.py
```

## 💎 核心技能详解

### 哨兵智能体 (The Sentinel)

**技能1: 清算流监控**
- 监控全网爆仓数据（CoinGlass）
- 1分钟内爆仓超过$1000万 → 触发级联警报
- 这是暴跌反弹的最强信号

**技能2: 巨鲸追踪**
- 监控XAUT大额转账（Whale Alert）
- 巨鲸转入交易所 → 潜在抛压预警
- 单笔超过$50万触发通知

**技能3: 宏观情感分析**
- NLP分析新闻情感（Twitter、Bloomberg）
- 特殊规则：Tether调查 → 最高级别警报
- 地缘政治 → 黄金看涨信号

### 分析师智能体 (The Analyst)

**技能4: 公允价值计算**
```python
Fair Value = XAU/USD × USDT/USD
Spread% = (XAUT_CEX - Fair_Value) / Fair_Value
Z-Score = (Spread - μ) / σ

# 交易信号
Z < -3: STRONG_BUY (极度低估)
Z > +3: STRONG_SELL (极度高估)
```

**技能5: 订单簿失衡率 (OBI)**
```python
OBI = (∑V_bids - ∑V_asks) / (∑V_bids + ∑V_asks)

# 吸筹信号
OBI从-0.9回升至-0.6 → 巨鲸吸筹
```

**技能6: 成交量高潮识别**
- 成交量 > 5× 平均成交量 + 大阴线
- 标志恐慌抛售高潮
- 等待下一根K线确认不再创新低

### 狙击手智能体 (The Sniper)

**技能7: 阶梯式接针**
```python
资金分配: 10%, 15%, 20%, 25%, 30%
挂单价位:
  Order 1: -0.5%
  Order 2: -1.0%
  Order 3: -1.8%
  Order 4: -3.0%
  Order 5: -5.0% (深度价值)
```

**技能8: 延迟套利**
- OKX先跌，Gate.io滞后几百毫秒
- 在滞后交易所挂低价买单
- 等待价格传导，吃价差

**技能9: 冰山订单 (TWAP)**
- 大单拆分成小单
- 时间加权平均执行
- 降低市场冲击

### 执政官智能体 (The Governor)

**技能10: 动态ATR止损**
```python
Stop Loss = Entry Price - (K × ATR)

正常: K = 2.0
恐慌: K = 4.0 (给予更大波动空间)
```

**技能11: USDT脱锚熔断**
- USDT < $0.97 → 立即停止所有买入
- 持仓转换为USDC或BTC
- 防止USDT暴雷风险

**技能12: 交易所偿付能力监控**
- 监控交易所储备金
- 储备金下降>10% → 触发提币
- 防止FTX式崩盘

## ⚠️ 风险警告

### 这是一个**激进投机系统**，存在以下风险：

1. **爆仓风险**: 使用杠杆可能导致全部本金损失
2. **流动性风险**: 极端行情下可能无法成交
3. **交易所风险**: 交易所可能倒闭（如FTX）
4. **USDT风险**: USDT可能脱锚或暴雷
5. **技术风险**: 系统故障、网络延迟、API限流

### 生存法则

✅ **必须遵守**:
- 单次风险不超过总资金的2-5%
- 严格执行止损，绝不死扛
- 利润不过夜，及时提现
- 分散资金到2-3个交易所
- 定期检查交易所储备金

❌ **绝对禁止**:
- 全仓梭哈
- 不设止损
- 逆势加仓（非马丁格尔策略）
- 将所有资金放在一个交易所
- 忽视USDT脱锚警报

## 🛠️ 故障排查

### Redis连接失败
```bash
# 检查Redis是否运行
redis-cli ping
# 应返回: PONG

# 如果未运行，启动Redis
redis-server
```

### 交易所API错误
- 检查API密钥是否正确
- 确认API权限（需要交易权限）
- 检查IP白名单设置
- 查看API限流状态

### 飞书通知未收到
- 检查Webhook URL是否正确
- 测试Webhook: `curl -X POST <webhook_url> -d '{"msg_type":"text","content":{"text":"test"}}'`
- 检查机器人是否被移除群聊
