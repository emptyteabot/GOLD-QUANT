## 🔥 新增功能

### 1. 自动止盈止损
- **硬止损**：-10%自动平仓
- **硬止盈**：+30%自动平仓
- **智能止盈**：盈利15%+时，如果Agent强烈反向信号，自动平仓
- **移动止损**：盈利20%+时，止损线移至+10%保护利润

### 2. 持仓策略
- **可以一直持有**：如果黄金持续上涨，系统不会强制平仓
- **Agent综合判断**：只有在盈利15%+且Agent强烈反向时才智能止盈
- **适合"倒车接人"行情**：低位买入后可以持有到+30%止盈

### 3. 智能频率控制
- **超强信号（95%+）**：立即执行，无冷却
- **强信号（90%+）**：30分钟冷却
- **标准信号（85%+）**：2小时冷却
- **每日最多12次交易**

## 💡 实战逻辑

```
开仓 → 持仓监控（每5分钟）
  ├─ 亏损达-10% → 止损平仓
  ├─ 盈利达+30% → 止盈平仓
  ├─ 盈利15%+ 且 Agent强烈反向 → 智能止盈
  ├─ 盈利20%+ 回落至+10% → 移动止损
  └─ 否则继续持有（可以一直拿到+30%）
```
