## 核心模块

### 1. data_engine.py - 多源数据引擎

**功能：**
- 实时价格数据（OKX/Binance/GoldAPI）
- 订单簿数据（大单监控、买卖失衡）
- 领先指标（DXY美元指数、VIX波动率、US10Y收益率）
- 新闻数据（RSS + AI分析）
- Twitter情绪（华尔街大V监控）

**关键方法：**
```python
# 获取所有数据
all_data = await data_engine.fetch_all_data()

# 检测大单
large_orders = await data_engine.detect_large_orders()

# 获取DXY（黄金的死敌）
dxy = await data_engine.fetch_dxy()
```

**提前预警能力：**
- DXY暴涨 → 提前5-10秒预警黄金下跌
- 订单簿大单 → 提前3-8秒预警价格变动
- Twitter大V → 比新闻快30-60秒

- 订单簿特征（买卖失衡、深度分析）
- 情绪特征（新闻/Twitter情感）

**改进点：**

## 核心优势

### 1. 提前预警（不是事后通知）

**传统系统：**
```
价格下跌 → 检测到 → 发送通知
延迟：0秒（但已经跌了）
```

**本系统：**
```
DXY暴涨 → 立即预警 → 5-10秒后 → 黄金下跌
提前量：5-30秒
```

**实现方式：**
- 监控领先指标（DXY、US10Y）
- 订单簿大单监控
- Twitter实时监控
- 新闻AI分析

### 2. 多策略组合

**单策略问题：**
- 趋势策略在震荡市亏损
- 均值回归在趋势市亏损

**多策略优势：**
- 策略互补
- 降低回撤
- 提高稳定性

**本系统策略：**
- Dual Thrust（趋势）
- 均值回归（震荡）
- 订单簿（微观）
- 宏观指标（基本面）

### 3. 严格风控

**Kelly公式：**
```
最优仓位 = (胜率 × 盈亏比 - 败率) / 盈亏比
```

**VaR风险度量：**
```
VaR(95%) = 在95%置信度下的最大损失
```

**动态止损：**
```
止损距离 = ATR × 2
（波动率高 → 止损宽，波动率低 → 止损紧）
```

### 4. 完整特征工程

**技术指标：** 30+
- 趋势：SMA/EMA/MACD
- 动量：RSI/CCI/MOM/ROC
- 波动：ATR/布林带
- 成交量：OBV/AD/ADOSC

**价量特征：** 20+
- 价量背离
- 价量共振
- 振幅分析

**订单簿特征：** 15+

**宏观特征：** 10+
