## ⚙️ 高级配置

### 1. 配置Google搜索（可选）

如果你想启用联网搜索，需要配置Google API：

1. 访问：https://console.cloud.google.com/
2. 创建项目
3. 启用 Custom Search API
4. 获取 API Key 和 CX

5. 在 `.env` 文件中添加：
```
GOOGLE_API_KEY=你的API密钥
GOOGLE_CX=你的搜索引擎ID
```

**不配置也能用！** 系统会自动跳过联网搜索。

---

### 2. 配置Twitter监控（可选）

1. 访问：https://developer.twitter.com/
2. 申请开发者账号
3. 获取 API Key

4. 在 `.env` 文件中添加：
```
TWITTER_API_KEY=你的API密钥
TWITTER_API_SECRET=你的API密钥
```

**不配置也能用！** 系统会自动跳过Twitter监控。

---

### 3. 配置飞书通知（必须）

在 `.env` 文件中添加：
```
FEISHU_WEBHOOK_URL=你的飞书机器人webhook地址
```
