## ✅ 第5步：学习关键技术（今晚）

### 必学内容（30分钟）

#### 1. 趋势判断（10分钟）
```
打开 TradingView
搜索：XAUTUSD
添加指标：
• MA5（红色）
• MA10（蓝色）
• MA20（绿色）

规则：
✅ MA5 > MA10 > MA20 = 上涨趋势（做多）
❌ MA5 < MA10 < MA20 = 下跌趋势（观望）
```

#### 2. 支撑阻力（10分钟）
```
关键价格位：
阻力：$4,700 / $4,750 / $4,800
支撑：$4,600 / $4,550 / $4,500

规则：
✅ 突破阻力 = 做多机会
✅ 跌破支撑 = 观望或做空
```

#### 3. 止损止盈（10分钟）
```
止损公式：
止损价 = 入场价 × (1 - 止损%)

止盈公式：
止盈价 = 入场价 × (1 + 止盈%)

推荐比例：
止损：-2% 到 -3%
止盈：+5% 到 +10%
风险收益比：1:2 或更高
```
