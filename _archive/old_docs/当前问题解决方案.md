## 🎯 解决方案（按优先级）

### 方案1：修改DNS服务器 ⭐⭐⭐

#### Windows系统操作步骤：

1. **打开网络连接**
   ```
   Win + R → 输入 ncpa.cpl → 回车
   ```

2. **修改DNS**
   - 右键你的网络连接（以太网/WLAN）
   - 点击"属性"
   - 双击"Internet 协议版本 4 (TCP/IPv4)"
   - 选择"使用下面的DNS服务器地址"
   - 首选DNS：`223.5.5.5` (阿里DNS)
   - 备用DNS：`114.114.114.114` (114DNS)
   - 点击"确定"

3. **刷新DNS缓存**
   ```bash
   # 管理员权限打开CMD
   ipconfig /flushdns
   ```

4. **测试连接**
   ```bash
   ping www.okx.com
   ping www.binance.com
   ```

**快速命令（管理员权限）：**

```powershell
# 打开PowerShell（管理员）
# 设置DNS（改成你的网络连接名称）
netsh interface ip set dns "以太网" static 223.5.5.5
netsh interface ip add dns "以太网" 114.114.114.114 index=2

# 刷新DNS
ipconfig /flushdns

# 测试
```

## 💡 常见原因

### 1. DNS服务器问题
**现象：** Could not contact DNS servers

**原因：** 
- 默认DNS不可用
- DNS服务器被墙
- 网络配置错误

**解决：** 改用国内DNS（223.5.5.5）

---

### 2. V2Ray未启用系统代理
**现象：** 浏览器能访问，Python不能

**原因：** 
- V2Ray只代理浏览器
- 系统代理未启用

**解决：** 启用V2Ray系统代理

---

### 3. 防火墙阻止
**现象：** 远程计算机拒绝连接

**原因：** 
- 防火墙阻止Python
- 端口被占用

**解决：** 
- 关闭防火墙测试
- 检查端口占用
