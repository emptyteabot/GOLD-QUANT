```python
    "drawdown_limit": 0.10     # 最大回撤 10%

```

### 7.2 仓位管理

```python
# 根据信号强度动态调整仓位
def calculate_position(signal_strength, volatility):
    """
    signal_strength: 0-1 (信号强度)
    volatility: 当前波动率
    """
    base_position = signal_strength * 0.3  # 最大30%
    vol_adjusted = base_position * (0.01 / volatility)
    return min(vol_adjusted, 0.3)
```
