## 🎯 系统特点

### 1. 只抓最强信号（85%+）

**为什么是85%而不是65%？**
```
信号65%：胜率约55%，交易频繁，手续费高
信号75%：胜率约60%，还不够稳
信号85%：胜率约70%，只抓最确定的机会 ✅
信号95%：胜率约80%，但机会太少
```

**结论：85%是最佳平衡点！**

### 2. 单次仓位10%（不是30%）

**为什么是10%？**
```
30%仓位：
• 3次亏损 = -27%（难以承受）
• 风险太大
• 不适合全部资金

10%仓位：
• 3次亏损 = -9%（可以接受）
• 可以多次加仓
• 保留应急资金 ✅
```

**结论：10%最安全！**

### 3. 动态杠杆10-15倍

**根据信号强度调整：**
```
信号90%+，共识85%+ → 15倍杠杆（极强信号）
信号85-90%，共识80%+ → 12倍杠杆（强信号）
信号80-85%，共识75%+ → 10倍杠杆（中等信号）
信号<80% → 不交易（等待更好机会）
```

**结论：信号越强，杠杆越高！**
