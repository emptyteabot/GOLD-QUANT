## ⚙️ 配置说明

### 基础配置（.env）

```bash
# 飞书 Webhook（必填）
FEISHU_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/xxxxx

# 检查间隔（秒，默认 5）
PRICE_CHECK_INTERVAL=5

# 急跌阈值（默认 -0.2%）
THRESHOLD_PRICE_DROP_1M=-0.002

# 急涨阈值（默认 +0.3%）
THRESHOLD_PRICE_SPIKE_1M=0.003

# 预警冷却时间（秒，默认 300）
ALERT_COOLDOWN=300
```

### 高级配置（可选）

如果 Binance/OKX 不稳定，可以添加备用数据源：

```bash
# GoldAPI (免费 100 次/月)
# 注册: https://www.goldapi.io/
GOLDAPI_KEY=your_api_key

# Metals-API (免费 50 次/月)
# 注册: https://metals-api.com/
METALS_API_KEY=your_api_key
```

## 🔧 故障排查

### 问题 1: 所有数据源都失败

**原因：** 网络问题或 API 限流

**解决：**
```bash
# 1. 测试网络
ping www.binance.com

# 2. 增加检查间隔
PRICE_CHECK_INTERVAL=10

# 3. 配置备用数据源（GoldAPI/Metals-API）
```

### 问题 2: 收不到飞书通知

**检查清单：**
- [ ] Webhook URL 是否正确
- [ ] 机器人是否在群里
- [ ] 网络是否正常

**测试：**
```bash
# 手动触发一次测试
curl -X POST "你的webhook" -H "Content-Type: application/json" -d '{"msg_type":"text","content":{"text":"测试"}}'
```

### 问题 3: 预警太频繁

**调整阈值：**
```bash
# 更保守的设置
THRESHOLD_PRICE_DROP_1M=-0.005  # -0.5%
THRESHOLD_PRICE_SPIKE_1M=0.005  # +0.5%
ALERT_COOLDOWN=600              # 10分钟
```

## 💰 投资建议逻辑

### 急跌时（避免亏损）
1. **立即检查持仓** - 是否需要止损
2. **分析原因** - 技术性回调 vs 趋势反转
3. **等待反弹** - 不要盲目抄底
4. **关注新闻** - 美联储、地缘政治

### 急涨时（投机机会）
1. **确认突破** - 是否有效突破阻力位
2. **适量加仓** - 不要追高
3. **设置止盈** - 落袋为安
4. **警惕回调** - 假突破风险

## 🎓 黄金交易知识

### 影响黄金价格的因素

1. **美元指数** - 负相关（美元涨，黄金跌）
2. **美债收益率** - 负相关（收益率涨，黄金跌）
3. **通胀预期** - 正相关（通胀涨，黄金涨）
4. **地缘政治** - 避险需求推高金价
5. **美联储政策** - 鹰派打压，鸽派利好

### 关键时间点（北京时间）

- **20:30** - 美国经济数据（非农、CPI等）
- **21:00** - 美联储官员讲话
- **02:00** - 美联储议息会议
- **08:30** - 中国经济数据
