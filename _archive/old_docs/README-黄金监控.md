## ⚙️ 配置文件（.env）

```bash
# ============================================
# 飞书配置（必填）
# ============================================
FEISHU_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/your-webhook-key

# ============================================
# 监控配置（可选，有默认值）
# ============================================

# 检查间隔（秒）
PRICE_CHECK_INTERVAL=5

# 急跌阈值（-0.2% = -0.002）
THRESHOLD_PRICE_DROP_1M=-0.002

# 急涨阈值（+0.3% = 0.003）
THRESHOLD_PRICE_SPIKE_1M=0.003

# 预警冷却时间（秒，防止频繁通知）
ALERT_COOLDOWN=300

# ============================================
# 高级数据源（可选）
# ============================================

# GoldAPI (免费 100 次/月)
# 注册: https://www.goldapi.io/
# GOLDAPI_KEY=your_api_key

# Metals-API (免费 50 次/月)
# 注册: https://metals-api.com/
# METALS_API_KEY=your_api_key
```

## 🔧 故障排查

### 问题 1: 所有数据源都失败

**症状：**
```
❌ Binance 获取失败
❌ OKX 获取失败
❌ 所有数据源均失败
```

**原因：**
- 网络问题
- API 限流
- 防火墙拦截

**解决：**
1. 检查网络连接
2. 增加检查间隔（`PRICE_CHECK_INTERVAL=10`）
3. 配置备用数据源（GoldAPI/Metals-API）
4. 使用 VPN（如果在受限网络）

### 问题 2: 收不到飞书通知

**检查清单：**
- [ ] `.env` 文件中 `FEISHU_WEBHOOK_URL` 是否正确
- [ ] 机器人是否已添加到群聊
- [ ] 网络是否正常
- [ ] Webhook URL 是否过期

**测试方法：**
```bash
双击运行: 测试黄金.bat
选择: 3 (测试飞书连接)
```

### 问题 3: 预警太频繁

**调整方案：**
```bash
# 提高阈值
THRESHOLD_PRICE_DROP_1M=-0.005  # -0.5%
THRESHOLD_PRICE_SPIKE_1M=0.005  # +0.5%

# 延长冷却时间
ALERT_COOLDOWN=600  # 10分钟
```

## 💡 投资建议说明

### 急跌时的建议逻辑

1. **检查持仓风险**
   - 计算当前浮亏
   - 评估止损位置
   - 判断是否需要减仓

2. **关注市场新闻**
   - 美联储官员讲话
   - 经济数据公布
   - 地缘政治事件

3. **考虑止损策略**
   - 技术性回调：等待反弹
   - 趋势反转：果断止损

4. **等待反弹机会**
   - 不要盲目抄底
   - 等待企稳信号
   - 分批建仓

### 急涨时的建议逻辑

1. **关注突破确认**
   - 是否突破关键阻力位
   - 成交量是否配合
   - 是否有效突破

2. **考虑适量加仓**
   - 不要追高
   - 控制仓位
   - 分批买入

3. **设置止盈目标**
   - 计算目标价位
   - 分批止盈
   - 落袋为安

4. **警惕假突破**
   - 观察回踩确认
   - 防止诱多陷阱
   - 设置止损保护

## 🎓 黄金投资知识

### 影响黄金价格的核心因素

1. **美元指数（DXY）** - 负相关
   - 美元涨 → 黄金跌
   - 美元跌 → 黄金涨

2. **美债收益率** - 负相关
   - 收益率涨 → 黄金跌
   - 收益率跌 → 黄金涨

3. **通胀预期** - 正相关
   - 通胀预期升温 → 黄金涨
   - 通胀预期降温 → 黄金跌

4. **地缘政治** - 避险需求
   - 风险事件 → 黄金涨
   - 风险缓和 → 黄金跌

5. **美联储政策** - 核心驱动
   - 鹰派（加息）→ 黄金跌
   - 鸽派（降息）→ 黄金涨
