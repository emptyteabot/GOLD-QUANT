## 系统简介

### 功能
这是一个**黄金价格监控系统**，帮助你：
- ✅ 实时监控黄金价格
- ✅ 价格异常时自动预警
- ✅ 通过飞书推送通知
- ✅ 提供投资建议

### 特点
- 🔔 **急跌预警** - 避免亏损
- 📈 **急涨预警** - 把握投机机会
- 💡 **智能建议** - AI 分析市场
- 📱 **飞书推送** - 第一时间通知

## 快速开始

### 第一步：诊断网络

**双击运行：** `诊断网络.bat`

这会测试你的网络能否访问黄金价格数据源。

**预期结果：**
```
✅ Binance: 连接成功
✅ 黄金价格: $2,650.23/盎司
```

**如果失败：**
- 检查网络连接
- 关闭防火墙/代理
- 或者申请 GoldAPI（见下文）

### 第二步：配置飞书

1. 打开飞书，进入要接收通知的群聊
2. 点击右上角 `···` → `设置` → `群机器人`
3. 点击 `添加机器人` → `自定义机器人`
4. 设置机器人名称（如：黄金监控助手）
5. 复制 Webhook URL

6. 在项目文件夹中找到 `.env` 文件，打开编辑：
```
FEISHU_WEBHOOK_URL=粘贴你的Webhook URL
```

### 第三步：启动监控

**双击运行：** `测试黄金.bat`

选择 `2. 启动黄金监控系统`

**系统会：**
1. 发送启动通知到飞书
2. 每 5 秒检查黄金价格
3. 发现异常立即预警

## 配置说明

### 必填配置

在 `.env` 文件中：

```bash
# 飞书 Webhook（必填）
FEISHU_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/xxxxx
```

### 可选配置

```bash
# 检查间隔（秒，默认 5）
PRICE_CHECK_INTERVAL=5

# 急跌阈值（默认 -0.2%）
THRESHOLD_PRICE_DROP_1M=-0.002

# 急涨阈值（默认 +0.3%）
THRESHOLD_PRICE_SPIKE_1M=0.003

# 预警冷却时间（秒，默认 300）
ALERT_COOLDOWN=300
```

### 数据源配置（可选）

如果 Binance/OKX 无法访问，可以申请免费 API：

#### 方案 A：GoldAPI（推荐）
1. 访问：https://www.goldapi.io/
2. 点击 "Get Free API Key"
3. 注册账号（邮箱验证）
4. 复制 API Key
5. 在 `.env` 中添加：
```bash
GOLDAPI_KEY=你的API密钥
```

**免费额度：** 100 次/月

#### 方案 B：Metals-API
1. 访问：https://metals-api.com/
2. 注册账号
3. 复制 API Key
4. 在 `.env` 中添加：
```bash
METALS_API_KEY=你的API密钥
```

**免费额度：** 50 次/月

## 使用方法

### 日常监控

1. **启动系统**
   - 双击 `测试黄金.bat`
   - 选择 `2`
   - 保持窗口运行

2. **接收通知**
   - 系统会自动监控
   - 异常时推送到飞书
   - 包含投资建议

3. **停止系统**
   - 按 `Ctrl + C`
   - 或直接关闭窗口

### 重要时段监控

在重要事件期间（美联储会议、非农数据等），可以提高灵敏度：

编辑 `.env` 文件：
```bash
PRICE_CHECK_INTERVAL=2              # 2秒检查一次
THRESHOLD_PRICE_DROP_1M=-0.001     # -0.1% 就预警
THRESHOLD_PRICE_SPIKE_1M=0.001     # +0.1% 就预警
```

### 长线投资监控

如果只关注大波动：

```bash
PRICE_CHECK_INTERVAL=60             # 1分钟检查一次
THRESHOLD_PRICE_DROP_1M=-0.01      # -1% 才预警
THRESHOLD_PRICE_SPIKE_1M=0.01      # +1% 才预警
```

## 常见问题

### Q1: 所有数据源都失败怎么办？

**A:** 按以下步骤排查：

1. **运行诊断工具**
   ```
   双击：诊断网络.bat
   ```

2. **检查网络**
   - 能否访问百度？
   - 能否访问 Binance？
   - 是否有防火墙/代理？

3. **申请备用 API**
   - 注册 GoldAPI（推荐）
   - 或注册 Metals-API

### Q2: 收不到飞书通知？

**A:** 检查清单：

- [ ] Webhook URL 是否正确？
- [ ] 机器人是否在群里？
- [ ] 网络是否正常？
- [ ] 是否触发了预警条件？

**测试方法：**
```
双击：测试黄金.bat
选择：3 (测试飞书连接)
```

### Q3: 预警太频繁怎么办？

**A:** 调整阈值：

```bash
# 提高阈值（更保守）
THRESHOLD_PRICE_DROP_1M=-0.005     # -0.5%
THRESHOLD_PRICE_SPIKE_1M=0.005     # +0.5%

# 延长冷却时间
ALERT_COOLDOWN=600                  # 10分钟
```

### Q4: 需要一直开着电脑吗？

**A:** 是的，系统需要持续运行。

**解决方案：**
- 使用闲置电脑/笔记本
- 或部署到云服务器（阿里云/腾讯云）
- 或使用树莓派等低功耗设备

### Q5: 可以监控其他品种吗？

**A:** 当前版本专注黄金。

如需监控其他品种（白银、原油、美元指数等），请联系开发者定制。

## 投资建议

### 急跌时的应对策略

当收到急跌预警时：

1. **立即检查持仓**
   - 计算当前浮亏
   - 评估风险承受能力

2. **分析下跌原因**
   - 美元走强？
   - 美联储鹰派言论？
   - 技术性回调？

3. **决策**
   - **技术性回调** → 等待反弹，不要恐慌
   - **趋势反转** → 考虑止损，保护本金
   - **不确定** → 减仓观望

4. **不要盲目抄底**
   - 等待企稳信号
   - 分批建仓
   - 控制仓位

### 急涨时的应对策略

当收到急涨预警时：

1. **确认突破有效性**
   - 是否突破关键阻力位？
   - 成交量是否配合？
   - 是否有基本面支撑？

2. **评估加仓机会**
   - 当前仓位如何？
   - 还有多少资金？
   - 风险承受能力？

3. **决策**
   - **有效突破** → 适量加仓
   - **假突破** → 观望等待
   - **已满仓** → 设置止盈

4. **不要追高**
   - 等待回踩确认
   - 分批买入
   - 设置止损

### 影响黄金价格的关键因素

1. **美元指数（DXY）**
   - 美元涨 → 黄金跌
   - 美元跌 → 黄金涨

2. **美债收益率**
   - 收益率涨 → 黄金跌
   - 收益率跌 → 黄金涨

3. **通胀预期**
   - 通胀预期升温 → 黄金涨
   - 通胀预期降温 → 黄金跌

4. **地缘政治**
   - 风险事件 → 避险需求 → 黄金涨
   - 风险缓和 → 避险需求降低 → 黄金跌

5. **美联储政策**
   - 鹰派（加息）→ 黄金跌
   - 鸽派（降息）→ 黄金涨
