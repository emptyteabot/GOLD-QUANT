## 第3步：收到信号后下单（5分钟）

### 信号示例

当你收到这样的飞书消息：

```

• 入场价：$4,650

• 仓位：0.2 XAUT
• 保证金：$93

• momentum: buy

• 趋势：uptrend
• 突破阻力位 $4,640

立即行动！
```

### 判断是否下单

**检查清单：**

1. ✅ 信号强度 > 80%？
2. ✅ 至少2个策略看多？
3. ✅ 风险收益比 > 1:1？
4. ✅ 你有足够保证金？（$93）
5. ✅ 你同意这个交易？

**如果都是✅，就下单！**

### 在OKX下单

**步骤：**

1. **打开OKX APP**

2. **搜索交易对**
   - 点击顶部搜索框
   - 输入：XAUT/USDT
   - 选择"现货"或"合约"

3. **选择买入**
   - 点击"买入"按钮
   - 选择"限价"或"市价"

4. **输入参数**
   ```
   数量：0.2 XAUT
   价格：$4,650（限价）或市价
   杠杆：10x
   ```

5. **确认下单**
   - 检查参数
   - 点击"买入"
   - 确认

6. **设置止损止盈**
   - 进入"仓位"页面
   - 点击你的仓位
   - 点击"止盈止损"
   - 止损价：$4,550
   - 止盈价：$4,750
   - 确认

**完成！**

## ⚠️ 常见问题

### Q1: 系统启动失败？

**A: 检查Python环境**

```powershell
# 检查Python版本
python --version

# 应该显示：Python 3.10 或更高

# 如果没有，安装依赖：
cd "c:\Users\陈盈桦\Desktop\黄金"
pip install -r requirements.txt
```

### Q2: 没有收到飞书通知？

**A: 配置飞书Webhook**

1. 打开文件：`.env`
2. 添加：
   ```
   FEISHU_WEBHOOK_URL=你的webhook地址
   ```
3. 保存
4. 重启系统

### Q3: 信号太少？

**A: 这是正常的！**

- 系统只推送高概率机会（>75%）
- 不是每天都有交易机会
- 耐心等待才能抓住大机会

### Q4: 信号太多？

**A: 提高阈值**

编辑 `激进交易系统.py`，找到：

```python
if signal['action'] == 'buy' and signal['confidence'] >= 0.75:
```

改成：

```python
if signal['action'] == 'buy' and signal['confidence'] >= 0.85:
```

只推送85%以上的信号。

### Q5: 如何停止系统？

**A: 按 Ctrl+C**

在控制台窗口按 `Ctrl+C`，系统会安全关闭。
