## 🚀 快速开始

### 步骤 1: 创建飞书机器人

1. 打开飞书，进入要接收通知的群聊
2. 点击右上角 `···` → `设置` → `群机器人`
3. 点击 `添加机器人` → `自定义机器人`
4. 设置机器人名称（如：黄金监控助手）
5. 复制 Webhook URL（格式：`https://open.feishu.cn/open-apis/bot/v2/hook/...`）

### 步骤 2: 配置环境变量

在项目根目录创建 `.env` 文件：

```bash
# 飞书配置（必填）
FEISHU_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/your-webhook-key

# 监控配置（可选）
PRICE_CHECK_INTERVAL=2              # 价格检查间隔（秒）
THRESHOLD_PRICE_DROP_1M=-0.002     # 急跌阈值（-0.2%）
THRESHOLD_PRICE_SPIKE_1M=0.003     # 急涨阈值（+0.3%）
ALERT_COOLDOWN=300                  # 预警冷却时间（秒）
```

### 步骤 3: 安装依赖

```bash
pip install -r requirements.txt
```

如果没有 `requirements.txt`，手动安装：

```bash
pip install ccxt aiohttp python-dotenv
```

### 步骤 4: 测试飞书连接

```bash
python test_feishu.py
```

你应该会在飞书群中收到 6 条测试消息：
- ✅ 欢迎消息
- ✅ 价格更新
- ✅ 急跌预警
- ✅ 急涨预警
- ✅ 帮助信息
- ✅ 每日报告

### 步骤 5: 启动监控系统

```bash
python main_interactive.py
```

## 🔧 高级配置

### 自定义监控交易对

编辑 `main_interactive.py`，修改 `symbols` 字典：

```python
self.symbols = {
    'btc': 'BTC/USDT',
    'eth': 'ETH/USDT',
    'sol': 'SOL/USDT',  # 添加 Solana
    'bnb': 'BNB/USDT',  # 添加 BNB
}
```

### 调整预警灵敏度

在 `.env` 文件中调整：

```bash
# 更激进（更频繁预警）
THRESHOLD_PRICE_DROP_1M=-0.001    # -0.1%
THRESHOLD_PRICE_SPIKE_1M=0.001    # +0.1%

# 更保守（减少预警）
THRESHOLD_PRICE_DROP_1M=-0.005    # -0.5%
THRESHOLD_PRICE_SPIKE_1M=0.005    # +0.5%
```

### 修改检查频率

```bash
# 高频监控（做市商级别）
PRICE_CHECK_INTERVAL=1    # 1秒

# 低频监控（节省资源）
PRICE_CHECK_INTERVAL=10   # 10秒
```

## 🐛 故障排查

### 问题 1: 收不到飞书消息

**检查清单：**
1. ✅ Webhook URL 是否正确
2. ✅ 机器人是否已添加到群聊
3. ✅ 网络连接是否正常
4. ✅ 运行 `python test_feishu.py` 测试

### 问题 2: 价格获取失败

**可能原因：**
- 网络问题（OKX API 访问受限）
- 交易对不存在
- API 限流

**解决方案：**
```bash
# 测试 OKX 连接
python okx_monitor.py
```

### 问题 3: 命令无响应

**注意：**
- 当前版本的命令处理需要飞书开放平台的**事件订阅**功能
- Webhook 机器人只能**发送消息**，不能**接收消息**
- 如需完整交互功能，需要升级为飞书应用

**临时方案：**
- 使用预设的订阅功能（所有人都会收到预警）
- 通过修改代码调整参数

## 📊 监控指标说明

### 价格变化率

- **1分钟涨跌幅**: 最近 1 分钟的价格变化百分比
- **5分钟涨跌幅**: 最近 5 分钟的价格变化百分比

### 预警阈值

- **急跌阈值**: 默认 -0.2%（1分钟内跌幅超过此值触发预警）
- **急涨阈值**: 默认 +0.3%（1分钟内涨幅超过此值触发预警）

### 冷却时间

- 防止频繁预警
- 默认 300 秒（5分钟）
- 同一类型预警在冷却期内不会重复发送

## 🔒 安全建议

1. **不要泄露 Webhook URL** - 任何人获得 URL 都可以向群发消息
2. **定期更换机器人** - 如果 URL 泄露，删除旧机器人并创建新的
3. **限制群成员** - 只邀请信任的人加入监控群
4. **备份配置** - 定期备份 `.env` 文件

## 💡 常见问题

### Q: 为什么用 BTC 代替黄金？

A: 因为 OKX 没有直接的黄金交易对，BTC 与黄金有较高的相关性，可以作为代理指标。如果需要真实黄金价格，可以使用其他 API（如 Kitco、GoldAPI）。

### Q: 可以监控 A 股黄金 ETF 吗？

A: 可以，但需要接入 A 股数据源（如 Tushare、AKShare）。当前版本专注于加密货币市场。

### Q: 如何添加更多监控品种？

A: 修改 `main_interactive.py` 中的 `self.symbols` 字典，添加 OKX 支持的任何交易对。

### Q: 预警太频繁怎么办？

A: 调整 `.env` 中的阈值和冷却时间：
```bash
THRESHOLD_PRICE_DROP_1M=-0.005  # 提高阈值
ALERT_COOLDOWN=600              # 延长冷却时间
```
