## 🚀 使用流程

### 第1步：环境准备
```bash
# 安装依赖
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 第2步：配置
```bash
# 复制配置模板
copy env.ultimate.example .env

# 编辑配置文件
notepad .env

# 填入飞书 Webhook
FEISHU_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/你的webhook
```

### 第3步：测试
```bash
# 运行测试脚本
python test_ultimate.py

# 测试价格获取
python simple_price_monitor.py
```

### 第4步：启动
```bash
# 启动系统
python main_ultimate.py

# 或使用简化版
python 一键赚钱.py
```
