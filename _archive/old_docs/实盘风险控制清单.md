## 🎯 实盘运行规则

### 规则1: 严格止损

**永远不要抱有侥幸心理！**

```
场景: 系统提示止损 $2640，但你觉得"可能会反弹"

❌ 错误做法: 不止损，继续持有
✅ 正确做法: 立即止损，保护本金

结果: 
- 错误做法: 继续下跌到 $2600，亏损扩大到 5%
- 正确做法: 止损 $2640，亏损控制在 2%
```

**华尔街铁律**: 止损是为了活下来，活下来才能赚钱。

---

### 规则2: 分批建仓

**永远不要一次性重仓！**

```
场景: 系统提示"黄金即将上涨"

❌ 错误做法: 一次性买入 30% 仓位
✅ 正确做法: 分3次买入，每次 10%

原因:
- 第一次买入后，如果继续下跌，还有资金补仓
- 如果判断错误，损失较小
- 如果判断正确，可以加仓扩大利润
```

---

### 规则3: 不在重大数据前重仓

**非农/CPI 等重大数据发布前，减仓或空仓！**

```
重大数据发布时间 (北京时间):
- 非农就业: 每月第一个周五 20:30
- CPI 数据: 每月中旬 20:30
- 美联储决议: 每年8次，通常 02:00

操作建议:
- 数据发布前 1 小时: 减仓至 10% 以下
- 数据发布后 30 分钟: 观察市场反应
- 趋势明确后: 再考虑建仓
```

**原因**: 重大数据可能导致价格剧烈波动，系统可能来不及反应。

---

### 规则4: 每日复盘

**每天收盘后，花 10 分钟复盘！**

```
复盘内容:
1. 今日预警次数: ___
2. 预警准确次数: ___
3. 准确率: ___% (目标 > 60%)
4. 盈亏: ___% (单日亏损 > 5% 需要反思)
5. 最大回撤: ___% (> 10% 需要暂停)

反思问题:
- 哪些预警是准确的？为什么？
- 哪些预警是错误的？为什么？
- 有没有违反风险管理规则？
- 明天需要调整什么？
```

---

### 规则5: 定期休息

**连续亏损 3 天，强制休息 1 周！**

```
场景: 连续 3 天亏损

❌ 错误做法: "我要把亏损赚回来"，继续交易
✅ 正确做法: 停止交易，休息 1 周，反思问题

原因:
- 连续亏损说明市场环境不适合当前策略
- 情绪化交易会导致更大亏损
- 休息可以让你冷静下来，重新审视策略
```

**华尔街铁律**: 保护本金比赚钱更重要。

## 🚨 紧急情况处理

### 情况1: 系统故障

```
症状: 系统停止推送，或推送延迟

处理:
1. 立即停止系统: taskkill /F /IM pythonw.exe
2. 检查日志: logs/system.log
3. 运行诊断: python test_ultimate.py
4. 如果无法修复，手动监控或暂停交易
```

---

### 情况2: 网络中断

```
症状: 无法访问 Binance 或 API

处理:
1. 检查网络连接
2. 尝试使用代理或 VPN
3. 如果长时间无法恢复，平仓退出
```

---

### 情况3: 极端行情

```
症状: 价格在 1 分钟内暴涨/暴跌 > 5%

处理:
1. 不要慌张，不要追涨杀跌
2. 检查是否有重大新闻 (战争/美联储紧急决议)
3. 如果持有仓位，根据止损规则决定是否平仓
4. 如果空仓，观察 30 分钟后再决定是否入场
```

---

### 情况4: 连续误报

```
症状: 系统连续 5 次预警，但价格没有明显变化

处理:
1. 暂停系统
2. 检查配置: 阈值是否设置过于敏感
3. 调整参数后重新测试
4. 确认稳定后再启动
```

## 🎓 华尔街交易员的建议

### 1. 永远不要满仓

```
"The market can remain irrational longer than you can remain solvent."
市场保持非理性的时间，可能比你保持偿付能力的时间更长。
                                        —— 凯恩斯
```

**教训**: 即使你 100% 确信会涨，也不要满仓。因为市场可能先跌 20%，然后才涨 30%。

---

### 2. 止损是为了活下来

```
"Rule No.1: Never lose money. Rule No.2: Never forget rule No.1."
规则1: 永远不要亏钱。规则2: 永远不要忘记规则1。
                                        —— 巴菲特
```

**教训**: 止损不是认输，而是保护本金。只有活下来，才有机会赚钱。

---

### 3. 不要追涨杀跌

```
"Be fearful when others are greedy, and greedy when others are fearful."
别人贪婪时我恐惧，别人恐惧时我贪婪。
                                        —— 巴菲特
```

**教训**: 价格暴涨时，往往是风险最大的时候。价格暴跌时，往往是机会最大的时候。

---

### 4. 保持冷静

```
"The stock market is a device for transferring money from the impatient to the patient."
股市是一个将钱从急躁者转移到耐心者的装置。
                                        —— 巴菲特
```

**教训**: 不要因为一次亏损就慌张，也不要因为一次盈利就得意。保持冷静，坚持策略。
