## 💡 重要说明

### 关于命令交互

**当前限制：**
- Webhook 机器人只能**发送消息**，不能**接收消息**
- 所以 `/price`、`/status` 等命令**暂时无法使用**

**解决方案：**

#### 方案 A: 使用预设功能（推荐）
系统会自动：
- ✅ 监控价格变化
- ✅ 发送预警通知
- ✅ 显示实时数据

#### 方案 B: 升级为飞书应用（完整交互）
需要：
1. 注册飞书开放平台账号
2. 创建企业自建应用
3. 配置事件订阅
4. 获取 App ID 和 App Secret

如果需要完整交互功能，我可以帮你升级代码。

## 📝 配置检查清单

在运行前，确保 `.env` 文件包含：

```bash
# 必填
FEISHU_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/xxxxx

# 可选（有默认值）
PRICE_CHECK_INTERVAL=2
THRESHOLD_PRICE_DROP_1M=-0.002
THRESHOLD_PRICE_SPIKE_1M=0.003
ALERT_COOLDOWN=300
```
