### 4. 动量策略 📈

#### 策略原理
- **核心思想**: 强者恒强，弱者恒弱
- **信号生成**: 多周期动量共振
- **趋势过滤**: ADX趋势强度确认
- **成交量验证**: 放量确认信号

#### 技术指标
- **ROC**: 变动率（短期/中期/长期）
- **MOM**: 动量指标
- **ADX**: 平均趋向指数
- **Volume Ratio**: 成交量比率

#### 参数配置
```python
strategy = MomentumStrategy(
    short_period=10,      # 短期周期
    medium_period=20,     # 中期周期
    long_period=50,       # 长期周期
    adx_threshold=25.0,   # ADX阈值
    entry_threshold=0.6,  # 入场阈值
    exit_threshold=0.3    # 出场阈值
)
```

#### 适用场景
- ✅ 趋势市场
- ✅ 突破行情
- ✅ 单边上涨/下跌
- ❌ 震荡市场

**测试命令**:
```bash

```

## 🐛 常见问题

### Q1: PyTorch安装失败？
**A**: 访问 https://pytorch.org 选择合适的版本
```bash
# CPU版本
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
```

### Q2: TA-Lib安装失败？
**A**: 这是正常的，系统会自动使用pandas实现
```bash
# 或者使用pandas-ta
pip install pandas-ta
```

### Q3: Web面板无法访问？
**A**: 检查防火墙设置
```bash
# Windows防火墙允许5000端口
netsh advfirewall firewall add rule name="Flask" dir=in action=allow protocol=TCP localport=5000
```

### Q4: 机器学习模型训练太慢？
**A**: 减少训练轮数或使用GPU
```python
# 使用GPU
predictor = GoldPricePredictor(device='cuda')
```
