# XAUT暴富引擎 - 3步快速开始

## 第一步：安装依赖

双击运行：`安装XAUT依赖.bat`

系统会自动安装：
- Redis（消息总线）
- CCXT（交易所连接）
- NumPy（数学计算）
- 其他必要库

---

## 第二步：配置系统

编辑 `.env` 文件，填入以下配置：

### 必填项

```bash
# 飞书机器人Webhook（接收交易信号）
FEISHU_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/你的webhook

# OKX交易所API（实盘交易）
OKX_API_KEY=你的API_KEY
OKX_SECRET=你的SECRET
OKX_PASSWORD=你的PASSWORD

# 总资金（USDT）
TOTAL_CAPITAL=100000
```

### 如何获取飞书Webhook？

1. 打开飞书，创建一个群聊
2. 群设置 → 机器人 → 添加机器人 → 自定义机器人
3. 复制Webhook URL
4. 粘贴到 `.env` 文件

### 如何获取OKX API？

1. 登录OKX → API管理 → 创建API
2. 权限：勾选"交易"
3. 复制API Key、Secret、Password
4. 粘贴到 `.env` 文件

⚠️ **如果不配置API，系统将以模拟模式运行（不会真实交易）**

---

## 第三步：启动系统

双击运行：`启动XAUT暴富引擎.bat`

系统会自动：
1. 启动Redis
2. 启动4个智能体（哨兵、分析师、狙击手、执政官）
3. 开始监控市场

## 常见问题

### Q: 系统会自动交易吗？
A: 是的，配置API后会自动执行。如果不配置API，只会发送信号到飞书，需要手动交易。

### Q: 需要一直开着电脑吗？
A: 是的。建议部署到云服务器（AWS、阿里云）实现7x24小时运行。

### Q: 最低需要多少资金？
A: 建议至少$10,000 USDT。资金太少会影响策略效果。

### Q: 收益率有多少？
A: 根据历史回测，单次暴跌反弹可获得5%-15%收益。但**过往表现不代表未来收益**。

### Q: 风险有多大？
A: **极高风险**。可能损失全部本金。请只用闲钱投资。

系统会安全关闭所有智能体。
