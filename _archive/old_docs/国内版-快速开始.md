## 📋 3步开始

### 第1步：配置飞书Webhook

创建 `.env` 文件（在黄金文件夹里）：

```bash
# V2Ray代理（已自动配置）
HTTP_PROXY=socks5://127.0.0.1:11843
HTTPS_PROXY=socks5://127.0.0.1:11843

# 飞书Webhook（必需 - 改成你的）
FEISHU_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/你的webhook地址
```

**获取飞书Webhook：**
1. 打开飞书APP
2. 创建群或使用现有群
3. 群设置 → 机器人 → 添加机器人 → 自定义机器人
4. 输入名字（如：黄金信号）
5. 复制Webhook地址
6. 粘贴到上面的 `.env` 文件

## 🐛 常见问题

### Q1: OKX获取失败？
**答：** 
- 检查网络连接
- 尝试访问 www.okx.com
- 如果无法访问，系统会自动切换到Binance

### Q2: 没有收到飞书通知？
**答：**
- 检查 `.env` 文件中的Webhook地址
- 确保飞书机器人在群里
- 查看系统输出是否有错误

### Q3: 价格数据不准确？
**答：**
- PAXG价格 = 国际黄金价格
- 可能有小幅差异（套利空间）
- 以OKX实际价格为准
