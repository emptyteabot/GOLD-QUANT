## 3. 详细部署步骤

### 第1步：购买服务器

#### 阿里云购买流程

1. **注册账号**
   - 访问 https://www.aliyun.com
   - 注册并实名认证

2. **选择产品**
   - 产品 → 云服务器ECS
   - 点击"立即购买"

3. **配置选择**
   - 地域：选择离你近的（如华东、华北）
   - 实例规格：1核2GB
   - 镜像：Ubuntu 20.04 64位
   - 存储：40GB
   - 带宽：1Mbps

4. **安全组**
   - 勾选"HTTP(80)"
   - 勾选"HTTPS(443)"
   - 勾选"SSH(22)"

5. **设置密码**
   - 设置root密码（记住！）

6. **购买**
   - 确认订单
   - 支付

7. **等待创建**
   - 约5分钟
   - 记录公网IP地址

---

### 第2步：连接服务器

#### Windows用户

**方式1：使用PuTTY**

1. 下载PuTTY：https://www.putty.org/
2. 打开PuTTY
3. Host Name：输入服务器IP
4. Port：22
5. 点击"Open"
6. 输入用户名：root
7. 输入密码

**方式2：使用PowerShell**

```powershell
ssh root@你的服务器IP
# 输入密码
```

#### Mac/Linux用户

```bash
ssh root@你的服务器IP
# 输入密码
```

---

### 第3步：安装环境

连接成功后，执行以下命令：

```bash
# 1. 更新系统
apt update && apt upgrade -y

# 2. 安装Python 3.10
apt install python3.10 python3-pip git -y

# 3. 验证安装
python3 --version
# 应该显示：Python 3.10.x

# 4. 升级pip
pip3 install --upgrade pip
```

---

### 第8步：后台运行

#### 方式1：使用nohup（简单）

```bash
# 后台运行
nohup python3 国内版-一键赚钱.py > output.log 2>&1 &

# 查看日志
tail -f output.log

# 查看进程
ps aux | grep python

# 停止进程
kill -9 进程ID
```

#### 方式2：使用screen（推荐）

```bash
# 安装screen
apt install screen -y

# 创建会话
screen -S gold

# 运行程序
python3 国内版-一键赚钱.py

# 按 Ctrl+A，然后按 D 退出会话（程序继续运行）

# 重新进入会话
screen -r gold

# 查看所有会话
screen -ls

# 删除会话
screen -X -S gold quit
```

#### 方式3：使用systemd（最专业）

```bash
# 创建服务文件
nano /etc/systemd/system/gold-trading.service
```

输入以下内容：

```ini
[Unit]
Description=Gold Trading System
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/黄金
ExecStart=/usr/bin/python3 国内版-一键赚钱.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

保存后执行：

```bash
# 重载配置
systemctl daemon-reload

# 启动服务
systemctl start gold-trading

# 查看状态
systemctl status gold-trading

# 开机自启
systemctl enable gold-trading

# 查看日志
journalctl -u gold-trading -f

# 停止服务
systemctl stop gold-trading

# 重启服务
systemctl restart gold-trading
```

## 4. 自动化脚本

### 一键部署脚本

创建 `deploy.sh`：

```bash
#!/bin/bash

echo "================================"
echo "黄金交易系统 - 一键部署"
echo "================================"
echo ""

# 1. 更新系统
echo "[1/6] 更新系统..."
apt update && apt upgrade -y

# 2. 安装Python
echo "[2/6] 安装Python..."
apt install python3.10 python3-pip git screen -y

# 3. 安装依赖
echo "[3/6] 安装依赖..."
pip3 install aiohttp ccxt pandas numpy scipy statsmodels python-dotenv requests -i https://pypi.tuna.tsinghua.edu.cn/simple

# 4. 配置环境
echo "[4/6] 配置环境..."
read -p "请输入飞书Webhook URL: " webhook
echo "FEISHU_WEBHOOK_URL=$webhook" > .env

# 5. 测试运行
echo "[5/6] 测试运行..."
python3 china_data_monitor.py

# 6. 创建systemd服务
echo "[6/6] 创建服务..."
cat > /etc/systemd/system/gold-trading.service <<EOF
[Unit]
Description=Gold Trading System
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=$(pwd)
ExecStart=/usr/bin/python3 国内版-一键赚钱.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable gold-trading
systemctl start gold-trading

echo ""
echo "================================"
echo "✅ 部署完成！"
echo "================================"
echo ""
echo "查看状态: systemctl status gold-trading"
echo "查看日志: journalctl -u gold-trading -f"
echo "停止服务: systemctl stop gold-trading"
echo ""
```

使用方法：

```bash
chmod +x deploy.sh
./deploy.sh
```

## 5. 监控和维护

### 5.1 查看运行状态

```bash
# 查看服务状态
systemctl status gold-trading

# 查看实时日志
journalctl -u gold-trading -f

# 查看最近100行日志
journalctl -u gold-trading -n 100
```

### 5.2 重启服务

```bash
systemctl restart gold-trading
```

### 5.3 更新代码

```bash
# 停止服务
systemctl stop gold-trading

# 更新代码
cd /root/黄金
git pull  # 如果使用git

# 或者重新上传文件
# scp ...

# 重启服务
systemctl start gold-trading
```

### 5.4 查看资源使用

```bash
# 查看CPU和内存
top

# 查看磁盘
df -h

# 查看网络
netstat -tunlp
```

### 5.5 定时任务（可选）

每天自动重启：

```bash
# 编辑crontab
crontab -e

# 添加以下行（每天凌晨3点重启）
0 3 * * * systemctl restart gold-trading
```

## 7. 常见问题

### Q1: 服务器在哪个地区？
**答：** 选择离你近的地区，延迟更低。推荐华东或华北。

### Q2: 需要备案吗？
**答：** 不需要！只是运行程序，不对外提供Web服务。

### Q3: 如何保证安全？
**答：**
- 使用强密码
- 只开放必要端口（22）
- 定期更新系统

### Q4: 服务器挂了怎么办？
**答：**
- 使用systemd自动重启
- 设置监控告警
- 定期检查日志

### Q5: 能同时运行多个策略吗？
**答：** 可以！复制代码到不同目录，分别运行。
