## 🔥 第一层：立即可用（已实现）

### 1️⃣ **Dual Thrust 策略** ✅
**来源**: `衍生品小组第二次分享-dual thrust2.0`

**应用场景**: 黄金日内突破交易

**核心逻辑**:
```python
# 已实现在 quant_enhanced.py
Range = max(HH - LC, HC - LL)
上轨 = 开盘价 + k1 * Range
下轨 = 开盘价 - k2 * Range

# 突破上轨 → 做多信号
# 突破下轨 → 做空信号
```

**实战价值**: 
- ✅ 适合黄金高波动特性
- ✅ 参数可调 (k1=0.5, k2=0.5)
- ✅ 回测夏普比率通常 > 1.5

**使用方法**:
```bash
python quant_enhanced.py  # 测试 Dual Thrust
```

## 📚 第三层：学习资料（长期）

### 7️⃣ **Advances in Financial Machine Learning**
**作者**: Marcos López de Prado (量化大神)

**核心概念**:
- **Fractional Differentiation**: 保持平稳性的同时保留记忆
- **Meta-Labeling**: 用ML决定是否交易，而不是预测方向
- **Purged K-Fold CV**: 避免时间序列交叉验证的数据泄露

**学习价值**: ⭐⭐⭐⭐⭐
这本书是量化金融的圣经，建议精读。
