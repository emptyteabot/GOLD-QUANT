### 第3步：安装Python（2分钟）

```bash
# 更新系统
apt update && apt upgrade -y

# 安装Python 3.10
apt install python3 python3-pip git -y

# 验证
python3 --version
# 应该显示：Python 3.10.x
```

---

### 第4步：上传代码（2分钟）

**方法1：使用scp（推荐）**

在你的电脑上运行：

```bash
# 压缩代码
cd c:\Users\陈盈桦\Desktop
tar -czf 黄金.tar.gz 黄金

# 上传到服务器
scp 黄金.tar.gz root@服务器IP:/root/

# 在服务器上解压
ssh root@服务器IP
cd /root
tar -xzf 黄金.tar.gz
```

**方法2：使用Git**

```bash
# 在服务器上
cd /root
git clone 你的代码仓库地址
```

---

### 第5步：安装依赖（1分钟）

```bash
cd /root/黄金
pip3 install -r requirements.txt
```

---

### 第6步：配置环境变量（1分钟）

```bash
# 创建.env文件
nano .env

# 添加配置
FEISHU_WEBHOOK_URL=你的飞书webhook地址

# 保存：Ctrl+O，回车，Ctrl+X
```

---

### 第7步：后台运行（1分钟）

**方法1：使用nohup（简单）**

```bash
# 后台运行
nohup python3 国内版-一键赚钱.py > output.log 2>&1 &

# 查看日志
tail -f output.log

# 查看进程
ps aux | grep python

# 停止进程
kill -9 进程ID
```

**方法2：使用systemd（推荐）**

```bash
# 创建服务文件
nano /etc/systemd/system/gold-trading.service
```

内容：

```ini
[Unit]
Description=Gold Trading System
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/黄金
ExecStart=/usr/bin/python3 国内版-一键赚钱.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

启动服务：

```bash
# 重载配置
systemctl daemon-reload

# 启动服务
systemctl start gold-trading

# 设置开机自启
systemctl enable gold-trading

# 查看状态
systemctl status gold-trading

# 查看日志
journalctl -u gold-trading -f

# 重启服务
systemctl restart gold-trading

# 停止服务
systemctl stop gold-trading
```

## 🔧 常见问题

### Q1: 连接不上服务器？

**A: 检查安全组规则**

1. 进入云服务器控制台
2. 找到"安全组"
3. 添加规则：
   ```
   端口：22
   协议：TCP
   来源：0.0.0.0/0
   ```

### Q2: 代码更新怎么办？

**A: 重新上传**

```bash
# 在本地
scp 黄金.tar.gz root@服务器IP:/root/

# 在服务器
cd /root
tar -xzf 黄金.tar.gz
systemctl restart gold-trading
```

### Q3: 如何查看飞书推送？

**A: 查看日志**

```bash
tail -f output.log | grep "飞书"
```

### Q4: 服务器重启后系统还运行吗？

**A: 使用systemd就会自动启动**

```bash
# 设置开机自启
systemctl enable gold-trading
```
