## 📋 部署步骤

### 第1步：安装依赖

打开命令行，执行：

```bash
cd c:\Users\陈盈桦\Desktop\黄金
pip install aiohttp pandas numpy python-dotenv requests
```

### 第2步：配置飞书Webhook

1. 打开飞书，创建一个群
2. 添加机器人，获取Webhook地址
3. 在 `.env` 文件中添加：

```
FEISHU_WEBHOOK_URL=你的飞书webhook地址
```

### 第3步：配置代理（可选）

如果你有代理（V2Ray/Clash等），可以配置：

在 `.env` 文件中添加：
```
HTTP_PROXY=http://127.0.0.1:7890
```

然后在 `超级终极系统.py` 中修改：
```python
USE_PROXY = True  # 改为True
```

**不配置也能用！** 系统使用国内数据源。

### 第4步：启动系统

**双击：**
```
启动超级系统.bat
```

A: 继承 `TradingAgent` 类，实现 `analyze` 方法。
