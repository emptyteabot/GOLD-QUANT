## ⚙️ 配置说明

### 默认配置（适合日常监控）
```bash
PRICE_CHECK_INTERVAL=5              # 5秒检查一次
THRESHOLD_PRICE_DROP_1M=-0.002     # -0.2% 触发急跌预警
THRESHOLD_PRICE_SPIKE_1M=0.003     # +0.3% 触发急涨预警
ALERT_COOLDOWN=300                  # 5分钟冷却时间
```

### 重要时段配置（美联储会议、非农数据）
```bash
PRICE_CHECK_INTERVAL=2              # 2秒检查
THRESHOLD_PRICE_DROP_1M=-0.001     # -0.1%
THRESHOLD_PRICE_SPIKE_1M=0.001     # +0.1%
ALERT_COOLDOWN=180                  # 3分钟
```

### 长线投资配置
```bash
PRICE_CHECK_INTERVAL=60             # 1分钟检查
THRESHOLD_PRICE_DROP_1M=-0.01      # -1%
THRESHOLD_PRICE_SPIKE_1M=0.01      # +1%
ALERT_COOLDOWN=3600                 # 1小时
```

## 💡 投资建议逻辑

### 急跌时
1. **检查持仓风险** - 计算浮亏
2. **分析原因** - 技术性 vs 趋势反转
3. **决策** - 止损 or 等待反弹
4. **不要盲目抄底** - 等待企稳信号

### 急涨时
1. **确认突破** - 是否有效突破阻力位
2. **评估机会** - 当前仓位和资金
3. **决策** - 适量加仓 or 观望
4. **不要追高** - 等待回踩确认
