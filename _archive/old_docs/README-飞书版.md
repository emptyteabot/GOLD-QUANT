# 🤖 飞书交互版黄金监控系统

一个基于飞书的智能交易监控系统，支持实时价格预警、命令交互和个性化订阅。

## ✨ 核心特性

- 🔔 **实时价格监控** - 基于 OKX 交易所，2秒级更新
- 🚨 **智能预警系统** - 急跌/急涨自动通知到飞书
- 💬 **飞书交互控制** - 通过命令查询价格、管理订阅
- 📊 **多维度分析** - 价格历史、涨跌幅、系统状态
- ⚙️ **个性化设置** - 自定义预警阈值和检查间隔

## 🚀 快速开始

### 1. 创建飞书机器人

1. 打开飞书群 → 设置 → 群机器人 → 添加自定义机器人
2. 复制 Webhook URL

### 2. 配置环境

创建 `.env` 文件：

```bash
FEISHU_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/your-webhook-key
```

### 3. 安装依赖

```bash
pip install ccxt aiohttp python-dotenv
```

### 4. 测试连接

```bash
# Windows
启动.bat

# 或直接运行
python test_feishu.py
```

### 5. 启动系统

```bash
python main_interactive.py
```

## 💬 飞书命令

| 命令 | 说明 |
|------|------|
| `/price` | 查询当前价格 |
| `/status` | 查看系统状态 |
| `/history` | 查看价格历史 |
| `/subscribe price` | 订阅价格预警 |
| `/settings` | 查看当前设置 |
| `/help` | 显示帮助 |

```

当前价格: $95,234.56
```

## ⚙️ 配置选项

在 `.env` 中自定义：

```bash
# 检查间隔（秒）
PRICE_CHECK_INTERVAL=2

# 预警阈值
THRESHOLD_PRICE_DROP_1M=-0.002    # -0.2%
THRESHOLD_PRICE_SPIKE_1M=0.003    # +0.3%

# 预警冷却时间（秒）
ALERT_COOLDOWN=300
```

## 🐛 故障排查

### 收不到飞书消息？
1. 检查 Webhook URL 是否正确
2. 运行 `python test_feishu.py` 测试
3. 确认机器人已添加到群聊

### 价格获取失败？
1. 检查网络连接
2. 运行 `python okx_monitor.py` 测试
3. 确认 OKX API 可访问

## 📊 监控指标

- **1分钟涨跌幅**: 最近 60 秒的价格变化
- **5分钟涨跌幅**: 最近 300 秒的价格变化
- **预警阈值**: 触发通知的涨跌幅度
- **冷却时间**: 防止频繁预警的间隔

## 🔒 安全提示

- ⚠️ 不要泄露 Webhook URL
- ⚠️ 定期更换机器人密钥
- ⚠️ 限制群成员访问
