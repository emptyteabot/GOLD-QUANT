### 2. 多策略组合

**单策略问题：**
- 趋势策略在震荡市亏损
- 均值回归在趋势市亏损

**多策略解决：**
```python
# 加权投票
signals = {
    'dual_thrust': 1,      # 趋势信号：做多
    'mean_reversion': 0,   # 震荡信号：观望
    'orderbook': 1,        # 订单簿：做多
    'macro': -1            # 宏观：做空
}

weights = {
    'dual_thrust': 0.4,
    'mean_reversion': 0.3,
    'orderbook': 0.2,
    'macro': 0.1
}

# 最终信号 = 加权平均
final_signal = sum(signals[k] * weights[k] for k in signals) / sum(weights.values())
# = (1*0.4 + 0*0.3 + 1*0.2 + (-1)*0.1) / 1.0
# = 0.5 → 做多
```

### 3. 严格风控

**Kelly公式：**
```python
# 最优仓位 = (胜率 × 盈亏比 - 败率) / 盈亏比
kelly = (0.6 * 2 - 0.4) / 2 = 0.4  # 40%仓位

# 但使用半Kelly更保守
position = kelly * 0.5 = 0.2  # 20%仓位
```

**VaR风险度量：**
```python
# 在95%置信度下的最大损失
var_95 = calculate_var(returns, confidence=0.95)
# 例如：VaR(95%) = 2.5%
# 意思：有95%的概率，损失不会超过2.5%
```

**动态止损：**
```python
# 止损距离 = ATR × 2
stop_loss = entry_price - atr * 2

# 波动率高 → ATR大 → 止损宽
# 波动率低 → ATR小 → 止损紧
```
