## 💡 为什么之前失败？

### 问题1：DNS污染
```
www.okx.com → 解析到 169.254.0.2 (错误的IP)
```

### 问题2：Python不走系统代理
- 浏览器能上外网（走系统代理）
- Python不能（需要手动指定代理）

### 解决方案
在代码中明确指定HTTP代理：
```python
async with session.get(url, proxy="http://127.0.0.1:10809")
```
