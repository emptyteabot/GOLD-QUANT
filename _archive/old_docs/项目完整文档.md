## 1. 项目概述

### 这是什么？

**黄金量化交易系统** - 一个专业的量化交易平台，用于监控黄金市场并自动生成交易信号。

### 核心价值

- 💰 **自动监控** - 24小时不间断监控黄金价格
- 📊 **多策略分析** - 3大交易策略协同决策
- 🔮 **提前预警** - 领先市场5-30秒发出信号
- 🛡️ **智能风控** - Kelly公式 + VaR/CVaR风险管理
- 📱 **实时推送** - 飞书/微信即时通知
- 🤖 **机器学习** - LSTM + XGBoost价格预测

### 适用场景

- ✅ 个人投资者 - 辅助交易决策
- ✅ 量化团队 - 策略研究和回测
- ✅ 学习研究 - 量化交易入门

## 3. 核心功能

### 3.1 数据引擎 (600行)

**功能：**
- 多交易所数据获取（OKX、Binance）
- 实时价格监控
- K线数据获取
- 订单簿分析
- 新闻数据抓取

**数据源：**

- 备用：Binance、新浪财经、东方财富
- 容错：自动切换数据源

---

### 3.2 特征工程 (500行)

**提取100+特征：**

#### 价格特征
- MA (5/10/20/60日均线)
- EMA (指数移动平均)
- BOLL (布林带)
- ATR (真实波动幅度)

#### 成交量特征
- 成交量均线
- 成交量比率
- OBV (能量潮)

#### 技术指标
- MACD
- RSI
- KDJ
- CCI

#### 订单簿特征
- 买卖比
- 大单监控
- 深度分析

---

### 3.3 交易策略 (1200行)

#### 策略1：Dual Thrust 2.0 (400行)
**类型：** 突破策略  
**原理：** 价格突破上下轨时入场  
**特点：**
- 动态K值调整
- 趋势跟踪
- 适合趋势市场

**权重：** 40%

---

#### 策略2：均值回归 (400行)
**类型：** 反转策略  
**原理：** 价格偏离均值时反向交易  
**特点：**
- 布林带分析
- Z-Score计算
- 协整检验

**权重：** 30%

---

#### 策略3：动量策略 (400行)
**类型：** 趋势策略  
**原理：** 跟随市场动量  
**特点：**
- MACD + RSI
- 多周期分析
- 趋势强度判断

**权重：** 30%

---

### 3.4 风险管理 (400行)

**功能：**

#### 仓位管理
- Kelly公式计算最优仓位
- 根据信号强度动态调整
- 最大仓位限制（30%）

#### 止损止盈
- 固定止损：2%
- 固定止盈：5%
- 移动止损：可选

#### 风险评估
- VaR (风险价值)
- CVaR (条件风险价值)
- 最大回撤控制

#### 熔断机制
- 单日亏损 > 5% → 停止交易
- 连续亏损 5次 → 停止交易
- 冷却期：1小时

---

### 3.5 领先指标 (600行)

**监控内容：**

#### 美元指数 (DXY)
- 提前时间：5-15秒
- 原理：DXY涨 → 黄金跌
- 阈值：±0.3%

#### 美债收益率 (US10Y)
- 提前时间：10-30秒
- 原理：收益率涨 → 黄金跌
- 阈值：±2bp

#### VIX恐慌指数
- 提前时间：5-20秒
- 原理：VIX涨 → 避险 → 黄金涨
- 阈值：±5%

#### 订单簿失衡
- 提前时间：3-10秒
- 原理：大单压盘/托盘
- 阈值：70%失衡

- **费用：** 学生机更便宜

---

### 7.2 部署步骤

#### 第1步：购买服务器
1. 登录阿里云/腾讯云
2. 选择ECS/云服务器
3. 配置：1核2G，Ubuntu 20.04
4. 购买并启动

#### 第2步：连接服务器
```bash
ssh root@你的服务器IP
```

#### 第3步：安装Python
```bash
# 更新系统
apt update && apt upgrade -y

# 安装Python 3.10
apt install python3.10 python3-pip -y

# 验证
python3 --version
```

#### 第4步：上传代码
```bash
# 方式1：使用git
git clone 你的代码仓库

# 方式2：使用scp
scp -r 黄金文件夹 root@服务器IP:/root/
```

#### 第5步：安装依赖
```bash
cd /root/黄金
pip3 install -r requirements.txt
```

#### 第6步：配置
```bash
# 创建.env文件
nano .env

# 填入配置
FEISHU_WEBHOOK_URL=你的webhook
```

#### 第7步：后台运行
```bash
# 使用nohup后台运行
nohup python3 国内版-一键赚钱.py > output.log 2>&1 &

# 查看日志
tail -f output.log

# 查看进程
ps aux | grep python
```

#### 第8步：开机自启（可选）
```bash
# 创建systemd服务
nano /etc/systemd/system/gold-trading.service
```

内容：
```ini
[Unit]
Description=Gold Trading System
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/黄金
ExecStart=/usr/bin/python3 国内版-一键赚钱.py
Restart=always

[Install]
WantedBy=multi-user.target
```

启用：
```bash
systemctl enable gold-trading
systemctl start gold-trading
systemctl status gold-trading
```

## 8. 常见问题

### Q1: 网络连接失败？
**答：** 
- 检查V2Ray是否开启全局代理
- 修改DNS为223.5.5.5
- 使用云服务器（无需代理）

### Q2: 价格不准确？
**答：**
- 误差 < $1 是正常的
- 系统获取的是最新成交价
- 手机APP可能显示买价/卖价

### Q3: 没有收到飞书通知？
**答：**
- 检查webhook地址是否正确
- 确认机器人在群里
- 查看系统日志

### Q4: 如何调整策略参数？
**答：**
- 编辑 `config_ultimate.py`
- 修改阈值、权重等参数
- 重启系统

### Q5: 能自动交易吗？
**答：**
- 当前版本只推送信号
- 不自动执行交易
- 需要手动下单
