## 🎯 使用流程

1. **首次使用**
   - 打开 `.env`，配置飞书 Webhook
   - 双击 `启动监控.bat`
   - 选择 1，测试数据源
   - 如果成功，选择 2 启动监控

2. **日常使用**
   - 双击 `启动监控.bat`
   - 选择 2
   - 保持窗口运行

3. **停止监控**
   - 按 `Ctrl + C`
   - 或直接关闭窗口
