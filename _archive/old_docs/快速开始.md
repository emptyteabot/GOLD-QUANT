# 💰 快速开始 - 3步赚钱

## 第1步：安装依赖（只需一次）

```bash
双击: 安装依赖.bat
```

等待2-5分钟，安装完成。

**如果安装失败也没关系**，系统会在运行时自动安装缺失的包。

---

## 第2步：配置飞书（只需一次）

创建 `.env` 文件，填入：

```bash
FEISHU_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/你的webhook
```

**获取webhook**:
1. 打开飞书
2. 创建群或使用现有群
3. 群设置 → 机器人 → 添加机器人 → 自定义机器人
4. 复制webhook地址粘贴到上面

---

## 第3步：启动系统

```bash
双击: 一键赚钱.bat
```

**完成！系统开始工作了。**

---

## 💡 你需要做什么

1. **看飞书** - 收到信号通知
2. **评估** - 看止损价格能否接受
3. **决定** - 是否交易
4. **执行** - 严格止损止盈

---

## ⚠️ 重要提醒

- ✅ 系统只推送信号，不自动交易
- ✅ 必须严格止损
- ✅ 控制仓位（单次≤30%）
- ✅ 只推送强信号（>50%）

---

## 🔧 遇到问题？

### 问题1：安装依赖失败

**解决**: 直接运行 `一键赚钱.bat`，系统会自动安装

### 问题2：没有收到飞书通知

**检查**:
1. `.env` 文件中的webhook地址是否正确
2. 飞书机器人是否在群里
3. 网络是否正常

### 问题3：系统报错

**解决**: 
1. 先运行 `安装依赖.bat`
2. 如果还报错，截图发给我
