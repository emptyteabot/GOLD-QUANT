## 🛡️ 风险管理（重要！）

### 铁律1：永远设置止损

```
❌ 错误：不设止损，死扛
✅ 正确：每笔交易必须有止损

止损位置：
• 激进：-2%
• 标准：-3%
• 保守：-5%
```

### 铁律2：控制单笔风险

```
❌ 错误：一次性梭哈
✅ 正确：单笔风险 ≤ 15%

计算公式：
仓位 = 账户资金 × 风险比例 / 止损幅度 / 杠杆
```

### 铁律3：分批建仓

```
❌ 错误：一次性买入
✅ 正确：分3-5次建仓

示例：
第1次：用 20% 资金试探
第2次：用 30% 资金加仓
第3次：用 50% 资金重仓
```

### 铁律4：盈利保护

```
❌ 错误：盈利回吐
✅ 正确：移动止损

规则：
盈利 10% → 止损移到开仓价（保本）
盈利 20% → 止损移到 +10%
盈利 30% → 止损移到 +20%
```

### 铁律5：日内止损

```
❌ 错误：无限亏损
✅ 正确：日内亏损 > 10% 停止交易

冷静期：24小时
复盘：找出错误
调整：优化策略
```

## ⚠️ 风险提示

### 必须知道的事实

1. **10倍杠杆风险极高**
   - 价格波动 1% = 账户波动 10%
   - 价格波动 10% = 账户归零

2. **不是每次都能赚钱**
   - 胜率 60% 已经很高
   - 关键是盈亏比

3. **情绪是最大敌人**
   - 贪婪 → 重仓 → 爆仓
   - 恐惧 → 过早止损 → 错过利润

4. **市场不可预测**
   - 黑天鹅事件随时可能发生
   - 必须有应急预案

### 应急预案

#### 情况1：连续亏损

```
连续亏损 3次 → 停止交易 24小时
连续亏损 5次 → 停止交易 1周
日内亏损 > 10% → 停止交易当天
```

#### 情况2：爆仓风险

```
维持保证金率 > 300% → 立即追加保证金
维持保证金率 > 400% → 平掉 50% 仓位
维持保证金率 > 500% → 全部平仓
```

#### 情况3：黑天鹅

```
价格暴跌 > 5% → 立即平仓
重大新闻 → 先平仓再观望
系统故障 → 手动平仓
```
