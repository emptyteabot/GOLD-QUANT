## 🖥️ 本地开发联调

### 快速启动

#### 方式1：一键启动（推荐）
```bash
# 双击运行
启动联调环境.bat

# 或命令行
./启动联调环境.bat
```

#### 方式2：手动启动

**启动后端**
```bash
cd backend
python app.py
```
后端运行在: http://localhost:8000

**启动前端**
```bash
cd frontend
npm install  # 首次运行
npm run dev
```
前端运行在: http://localhost:3000

### 测试联调

```bash
# 运行测试脚本
cd scripts
python test_integration.py

# 或双击
scripts/test_integration.bat
```

### 停止服务

```bash
# 双击运行
停止所有服务.bat
```

## ☁️ Railway部署联调

### 1. 部署后端

```bash
# 进入后端目录
cd backend

# 登录Railway
railway login

# 初始化项目
railway init

# 部署
railway up
```

部署后会得到后端URL，例如：
```
https://gold-advisor-backend.railway.app
```

### 2. 配置环境变量

在Railway后端项目中设置：
```bash
ENVIRONMENT=production
ALLOWED_ORIGINS=https://your-frontend.railway.app,https://your-frontend.vercel.app
```

### 3. 部署前端

```bash
# 进入前端目录
cd frontend

# 更新.env.production
NEXT_PUBLIC_API_URL=https://gold-advisor-backend.railway.app

# 部署到Railway
railway init
railway up

# 或部署到Vercel
vercel --prod
```

### 4. 验证部署

访问前端URL，检查：
- ✓ 页面正常加载
- ✓ API请求成功
- ✓ 数据正常显示

## 📡 API接口说明

### 基础信息

**Base URL (本地)**: `http://localhost:8000`
**Base URL (生产)**: `https://your-backend.railway.app`

### 端点列表

#### 1. 根路径
```http
GET /
```
返回系统基本信息和状态

#### 2. 市场状态
```http
GET /api/market-status
```
返回当前市场状态（开盘/收盘）

#### 3. 标的列表
```http
GET /api/instruments
```
返回所有支持的交易标的

#### 4. 实时行情
```http
GET /api/quotes?codes=518880,518800
```
参数：
- `codes`: 标的代码，逗号分隔

#### 5. K线数据
```http
GET /api/klines?code=518880&period=5&days=5
```
参数：
- `code`: 标的代码
- `period`: 周期（5/15/30/60/daily）
- `days`: 天数

#### 6. 交易信号
```http
GET /api/signals?codes=518880,518800
```
参数：
- `codes`: 标的代码，逗号分隔

#### 7. 宏观分析
```http
GET /api/macro
```
返回宏观市场分析

#### 8. 行情识别
```http
GET /api/regime?code=518880
```
参数：
- `code`: 标的代码

### 响应格式

所有API返回JSON格式：
```json
{
  "code": "518880",
  "name": "黄金ETF",
  "price": 5.123,
  "change_pct": 1.23
}
```

错误响应：
```json
{
  "detail": "错误信息"
}
```

## 🔧 常见问题

### 1. CORS错误

**问题**: 前端请求被CORS策略阻止

**解决**:
- 本地开发：后端已配置允许所有来源
- 生产环境：在Railway后端设置`ALLOWED_ORIGINS`环境变量

```bash
ALLOWED_ORIGINS=https://your-frontend.railway.app
```

### 2. 连接超时

**问题**: API请求超时

**解决**:
- 检查后端是否启动：访问 http://localhost:8000
- 检查防火墙设置
- 增加请求超时时间（frontend/utils/api.ts）

### 3. 数据不显示

**问题**: 前端页面空白或无数据

**解决**:
- 打开浏览器开发者工具（F12）
- 查看Console错误信息
- 查看Network请求状态
- 运行测试脚本诊断

### 4. 端口占用

**问题**: 端口8000或3000已被占用

**解决**:
```bash
# Windows
netstat -ano | findstr :8000
taskkill /PID <进程ID> /F

# 或修改端口
# 后端: backend/app.py 最后一行
# 前端: package.json scripts.dev
```

### 5. Railway部署失败

**问题**: Railway部署报错

**解决**:
- 检查railway.json配置
- 查看部署日志
- 确认requirements.txt包含所有依赖
- 检查环境变量设置
