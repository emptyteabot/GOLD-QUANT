## 🧪 测试体系 (新增)

### 快速开始

```bash
# 1. 验证测试环境
python verify_test_env.py

# 2. 安装测试依赖
pip install -r requirements_test.txt

# 3. 运行所有测试
python run_tests.py all

# 4. 查看覆盖率
python run_tests.py coverage
```

### 测试结构

```
tests/
├── unit/              # 单元测试 (35个用例)
├── integration/       # 集成测试 (16个用例)
├── performance/       # 性能测试 (9个用例)
└── security/          # 安全测试 (15个用例)
```

### 测试覆盖

- **风控模块**: 仓位计算、止损止盈、加仓逻辑
- **ML模型**: 模型训练、特征计算、信号生成
- **回测引擎**: 开平仓逻辑、统计计算
- **系统集成**: 模块协作、API交互
- **性能测试**: 速度、内存、并发
- **安全测试**: 风控限制、输入验证

### 测试指标

| 指标 | 目标 | 状态 |
|-----|------|------|
| 测试用例数 | 75+ | ✅ |
| 代码覆盖率 | > 80% | 🔄 待运行 |
| ML训练速度 | < 5秒 | ✅ |
| 决策速度 | < 50ms | ✅ |
| 回测速度 | > 10 bars/sec | ✅ |
