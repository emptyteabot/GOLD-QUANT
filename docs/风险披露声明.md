# AURUM风险披露声明

**版本**: v1.0
**发布日期**: 2026-02-16

---

## ⚠️ 重要警告

**请在使用AURUM系统前仔细阅读本风险披露声明**

金融市场交易具有高风险,可能导致您损失全部投资本金。量化交易系统不能消除风险,在某些情况下甚至可能放大风险。

**如果您不能承受全部本金损失,请勿使用本系统。**

---

## 一、市场风险

### 1.1 价格波动风险

**风险描述**:
- 黄金价格受多种因素影响,可能出现剧烈波动
- 单日波动可能超过5%,极端情况下可能超过10%
- 价格波动可能导致重大损失

**历史案例**:
- 2020年3月:黄金单日暴跌6.7%
- 2013年4月:黄金两日暴跌13%

**风险等级**: 🔴 **高**

### 1.2 杠杆风险

**风险描述**:
- AURUM系统支持最高20倍杠杆
- 杠杆会放大收益,同时也会放大损失
- 使用20倍杠杆时,价格波动5%即可能导致爆仓

**示例**:
```
本金: $1,000
杠杆: 20倍
持仓价值: $20,000

如果价格下跌5%:
损失 = $20,000 × 5% = $1,000
结果: 爆仓,本金全部损失
```

**风险等级**: 🔴 **极高**

### 1.3 流动性风险

**风险描述**:
- 市场流动性不足时,可能无法及时平仓
- 极端行情下,可能出现滑点或无法成交
- 可能导致损失扩大或无法止损

**风险等级**: 🟡 **中**

### 1.4 系统性风险

**风险描述**:
- 全球经济危机、金融市场崩盘
- 重大政策变化(如禁止杠杆交易)
- 交易所倒闭或跑路
- 不可抗力事件(战争、自然灾害等)

**风险等级**: 🟡 **中**

## 二、技术风险

### 2.1 系统故障风险

**风险描述**:
- 软件可能存在bug或设计缺陷
- 系统可能在关键时刻崩溃或失灵
- 可能导致无法及时交易或错误交易

**可能后果**:
- 错过最佳交易时机
- 无法及时止损
- 执行错误的交易指令
- 资金损失

**风险等级**: 🟡 **中**

### 2.2 网络风险

**风险描述**:
- 网络中断可能导致无法连接交易所
- 网络延迟可能导致交易延误
- DDoS攻击可能导致服务不可用

**风险等级**: 🟡 **中**

### 2.3 数据风险

**风险描述**:
- 数据源可能提供错误或延迟的数据
- 数据错误可能导致错误的交易决策
- 历史数据可能不完整或不准确

**风险等级**: 🟡 **中**

### 2.4 安全风险

**风险描述**:
- API密钥可能被盗或泄露
- 黑客攻击可能导致资金损失
- 恶意软件可能窃取敏感信息

**防范措施**:
- 🔐 妥善保管API密钥
- 🔐 设置IP白名单
- 🔐 限制API权限(禁用提现)
- 🔐 使用双因素认证

**风险等级**: 🔴 **高**

## 三、策略风险

### 3.1 过拟合风险

**风险描述**:
- 策略在历史数据上表现良好,但在实盘中可能失效
- 机器学习模型可能过度拟合历史数据
- 历史收益不代表未来表现

**重要提示**:
```
⚠️ 回测收益率≠实盘收益率
历史数据仅供参考,不构成未来收益保证
```

**风险等级**: 🔴 **高**

### 3.2 模型失效风险

**风险描述**:
- 市场环境变化可能导致策略失效
- 量化策略的有效性可能随时间衰减
- 黑天鹅事件可能导致策略完全失效

**历史案例**:
- 2020年3月:COVID-19疫情导致多数量化策略失效
- 2008年金融危机:大量量化基金巨亏

**风险等级**: 🔴 **高**

### 3.3 参数风险

**风险描述**:
- 不当的参数设置可能导致重大损失
- 过于激进的参数可能导致频繁止损
- 过于保守的参数可能错过机会

**建议**:
- ✅ 充分回测后再使用实盘
- ✅ 从保守参数开始
- ✅ 逐步优化参数
- ✅ 避免频繁调整参数

**风险等级**: 🟡 **中**

## 四、操作风险

### 4.1 配置错误风险

**风险描述**:
- 错误的配置可能导致意外交易
- 杠杆设置过高可能导致爆仓
- 止损设置不当可能导致重大损失

**常见错误**:
- ❌ 杠杆设置过高(>20倍)
- ❌ 止损比例过大(>5%)
- ❌ 仓位比例过大(>90%)
- ❌ API权限设置不当

**风险等级**: 🟡 **中**

### 4.2 监控不足风险

**风险描述**:
- 长时间无人监控可能导致问题未及时发现
- 系统异常可能未及时处理
- 市场突变可能未及时应对

**建议**:
- ✅ 定期检查系统运行状态
- ✅ 设置飞书/邮件推送
- ✅ 关注重大市场事件
- ✅ 极端行情时人工介入

**风险等级**: 🟡 **中**

## 八、风险管理建议

### 8.1 资金管理

**建议**:
1. **只用闲钱**:只投入您能承受全部损失的资金
2. **分散投资**:不要将所有资金投入单一策略
3. **控制杠杆**:建议杠杆≤5倍(实盘)
4. **控制仓位**:建议仓位≤50%

### 8.2 风险控制

**建议**:
1. **严格止损**:设置合理的止损比例(建议2-3%)
2. **移动止损**:盈利后及时锁定利润
3. **最大回撤限制**:设置最大回撤阈值(建议15-20%)
4. **定期评估**:定期评估策略表现,及时调整

### 8.3 操作建议

**建议**:
1. **充分测试**:实盘前充分回测和模拟盘测试
2. **小资金起步**:从小资金开始,逐步增加
3. **持续学习**:不断学习金融知识和量化技术
4. **保持理性**:不要因短期盈亏而情绪化操作
