## 策略系统概述

### 什么是策略？

策略是一套**交易规则**，告诉系统什么时候买、什么时候卖、买多少。

AURUM使用**多策略投票机制**：
- 5个AI专家各自分析
- 每个专家给出建议和置信度
- 系统综合所有建议做决策

### 策略架构

```
┌─────────────────────────────────────┐
│         策略投票系统                 │
└─────────────────────────────────────┘
                │
    ┌───────────┼───────────┐
    ▼           ▼           ▼
┌────────┐ ┌────────┐ ┌────────┐
│宏观20% │ │技术20% │ │ ML 20% │
└────────┘ └────────┘ └────────┘
    ▼           ▼           ▼
┌────────┐ ┌────────┐
│XAUT20% │ │RSI 20% │
└────────┘ └────────┘
                │
                ▼
        ┌──────────────┐
        │  综合决策    │
        │ 做多/做空/观望│
        └──────────────┘
```

## 基础配置

### 1. 策略权重配置

编辑 `config.py`：

```python
# 策略权重（总和必须=1.0）
STRATEGY_WEIGHTS = {
    'macro': 0.20,      # 宏观分析 20%
    'technical': 0.20,  # 技术分析 20%
    'ml': 0.20,         # 机器学习 20%
    'xaut': 0.20,       # XAUT策略 20%
    'rsi': 0.20         # RSI策略 20%
}
```

**权重含义：**
- 权重越高，该策略影响力越大
- 总和必须等于1.0
- 建议单个策略权重不超过30%

### 2. 信号阈值配置

```python
# 信号强度阈值
MIN_SIGNAL_STRENGTH = 0.2    # 最小20%才考虑交易
STRONG_SIGNAL = 0.6          # 60%以上为强信号

# 置信度阈值
MIN_CONFIDENCE = 0.5         # 最小50%置信度
HIGH_CONFIDENCE = 0.8        # 80%以上为高置信度
```

**阈值影响：**
- 阈值越高 → 交易越少 → 更保守
- 阈值越低 → 交易越多 → 更激进

```python
# walk_forward.py
def walk_forward_analysis(data, train_period=60, test_period=30):
    """
    滚动窗口分析

    train_period: 训练周期（天）
    test_period: 测试周期（天）
    """
    results = []

    for i in range(0, len(data) - train_period - test_period, test_period):
        # 训练集
        train_data = data[i:i+train_period]

        # 优化参数
        best_params = optimize_on_data(train_data)

        # 测试集
        test_data = data[i+train_period:i+train_period+test_period]

        # 测试表现
        test_result = backtest_with_params(test_data, best_params)

        results.append(test_result)

    return results
```

#### 示例：均线交叉策略

```python
# strategies/ma_cross.py

class MACrossStrategy:
    """
    均线交叉策略
    - 短期均线上穿长期均线 → 做多
    - 短期均线下穿长期均线 → 做空
    """

    def __init__(self, short_period=10, long_period=30):
        self.name = "均线交叉"
        self.short_period = short_period
        self.long_period = long_period

    def analyze(self, data):
        """
        分析数据并返回信号

        Args:
            data: DataFrame with OHLCV data

        Returns:
            signal: 1=做多, -1=做空, 0=观望
            confidence: 0-1之间的置信度
        """
        # 计算均线
        ma_short = data['close'].rolling(self.short_period).mean()
        ma_long = data['close'].rolling(self.long_period).mean()

        # 获取最新值
        current_short = ma_short.iloc[-1]
        current_long = ma_long.iloc[-1]
        prev_short = ma_short.iloc[-2]
        prev_long = ma_long.iloc[-2]

        # 检测交叉
        if prev_short <= prev_long and current_short > current_long:
            # 金叉 - 做多
            signal = 1
            # 计算置信度（基于均线距离）
            distance = (current_short - current_long) / current_long
            confidence = min(0.5 + distance * 10, 0.9)

        elif prev_short >= prev_long and current_short < current_long:
            # 死叉 - 做空
            signal = -1
            distance = (current_long - current_short) / current_long
            confidence = min(0.5 + distance * 10, 0.9)

        else:
            # 无交叉 - 观望
            signal = 0
            confidence = 0.5

        return signal, confidence
```

### 4. 高级策略示例

#### 多时间框架策略

```python
class MultiTimeframeStrategy:
    """
    多时间框架策略
    - 日线判断趋势
    - 4小时线判断入场
    - 1小时线判断出场
    """

    def __init__(self):
        self.name = "多时间框架"

    def analyze(self, data_1h, data_4h, data_1d):
        # 日线趋势
        trend = self.get_trend(data_1d)

        # 4小时入场信号
        entry_signal = self.get_entry_signal(data_4h)

        # 1小时确认
        confirmation = self.get_confirmation(data_1h)

        # 综合判断
        if trend == 1 and entry_signal == 1 and confirmation == 1:
            return 1, 0.8  # 做多，高置信度
        elif trend == -1 and entry_signal == -1 and confirmation == -1:
            return -1, 0.8  # 做空，高置信度
        else:
            return 0, 0.5  # 观望

    def get_trend(self, data):
        # 使用EMA判断趋势
        ema_50 = data['close'].ewm(span=50).mean()
        ema_200 = data['close'].ewm(span=200).mean()

        if ema_50.iloc[-1] > ema_200.iloc[-1]:
            return 1  # 上升趋势
        else:
            return -1  # 下降趋势

    def get_entry_signal(self, data):
        # 使用RSI判断入场
        rsi = self.calculate_rsi(data['close'], 14)

        if rsi < 30:
            return 1  # 超卖，做多
        elif rsi > 70:
            return -1  # 超买，做空
        else:
            return 0

    def get_confirmation(self, data):
        # 使用MACD确认
        macd, signal = self.calculate_macd(data['close'])

        if macd > signal:
            return 1  # 确认做多
        else:
            return -1  # 确认做空
```

```python
class AdaptiveStrategy:
    """
    自适应策略
    - 检测市场状态（趋势/震荡）
    - 根据市场状态调整策略权重
    """

    def detect_market_state(self, data):
        # 计算ADX判断趋势强度
        adx = self.calculate_adx(data)

        if adx > 25:
            return 'trending'  # 趋势市
        else:
            return 'ranging'   # 震荡市

    def get_adaptive_weights(self, market_state):
        if market_state == 'trending':
            # 趋势市：重视趋势跟踪策略
            return {
                'macro': 0.30,
                'technical': 0.30,
                'ml': 0.20,
                'xaut': 0.10,
                'rsi': 0.10
            }
        else:
            # 震荡市：重视均值回归策略
            return {
                'macro': 0.10,
                'technical': 0.20,
                'ml': 0.20,
                'xaut': 0.20,
                'rsi': 0.30
            }
```

## 最佳实践

### 1. 策略开发流程

```
1. 提出想法
   ↓
2. 编写代码
   ↓
3. 单元测试
   ↓
4. 回测验证
   ↓
5. 参数优化
   ↓
6. Walk-Forward验证
   ↓
7. 模拟盘测试
   ↓
8. 小资金实盘
   ↓
9. 逐步放大
```

### 2. 避免过拟合

**常见陷阱：**
- ❌ 过度优化参数
- ❌ 使用未来数据
- ❌ 只在单一市场测试
- ❌ 忽略交易成本

**防止方法：**
- ✅ 使用样本外数据验证
- ✅ Walk-Forward分析
- ✅ 保持策略简单
- ✅ 考虑滑点和手续费

### 3. 策略评估标准

**不仅看收益率，还要看：**
- 夏普比率（风险调整后收益）
- 最大回撤（最大亏损）
- 胜率（盈利交易占比）
- 盈亏比（平均盈利/平均亏损）
- 稳定性（不同时期表现）
