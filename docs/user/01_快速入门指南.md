## 📋 开始前的准备

### 你需要什么？

**必需：**
- ✅ 一台电脑（Windows/Mac/Linux）
- ✅ Python 3.9或更高版本
- ✅ 30分钟空闲时间
- ✅ 基本的命令行操作能力

**可选（实盘交易需要）：**
- 📱 OKX交易所账号
- 💰 至少$100的交易资金

## 🚀 第一步：安装系统

### 1.1 下载项目

```bash
# 方式1：从GitHub下载
git clone https://github.com/yourusername/aurum.git
cd aurum

# 方式2：直接下载ZIP包
# 解压后进入项目目录
```

### 1.2 安装依赖

```bash
# 安装Python依赖包
pip install -r requirements.txt

# 如果速度慢，使用国内镜像
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**预计时间：** 2-5分钟

---

## ⚙️ 第二步：配置系统

### 2.1 创建配置文件

```bash
# 复制配置模板
cp .env.example .env
cp .env.trading.example .env.trading
```

### 2.2 基础配置（回测模式）

编辑 `.env` 文件：

```bash
# 基础配置
MODE=backtest              # 回测模式
INITIAL_CAPITAL=1000       # 初始资金$1000
LEVERAGE=5                 # 杠杆倍数5倍
```

**注意：** 回测模式不需要API密钥，可以直接运行！

### 2.3 高级配置（实盘模式）

如果要实盘交易，编辑 `.env.trading`：

```bash
# OKX API配置
OKX_API_KEY=你的API密钥
OKX_SECRET_KEY=你的密钥
OKX_PASSPHRASE=你的密码

# 飞书通知
FEISHU_WEBHOOK_URL=你的webhook地址
```

**如何获取API密钥？** 参见 [API配置教程](./02_API配置教程.md)

## 📊 第四步：理解回测结果

### 关键指标解读

| 指标 | 含义 | 好坏标准 |
|------|------|----------|
| **收益率** | 赚了多少钱 | >0%为盈利 |
| **最大回撤** | 最大亏损幅度 | <10%为优秀 |
| **胜率** | 盈利交易占比 | >40%为良好 |
| **盈亏比** | 平均盈利/平均亏损 | >2为优秀 |

### 示例分析

```
收益率: +1.92%     ✅ 盈利
最大回撤: 1.64%    ✅ 风险很低
胜率: 40%          ✅ 合格
交易次数: 5笔      ✅ 不过度交易
```

**结论：** 这是一个稳健的策略！

## ❓ 常见问题

### Q1: 安装依赖失败怎么办？

**A:** 使用国内镜像：
```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### Q2: 回测结果和文档不一样？

**A:** 正常！市场数据每天变化，回测结果会有差异。关注趋势而非具体数字。

### Q3: 可以跳过回测直接实盘吗？

**A:** 强烈不建议！回测是验证策略的唯一方法。

### Q4: 多久能看到收益？

**A:** 量化交易是长期游戏。建议至少运行1个月再评估。

### Q5: 亏损了怎么办？

**A:**
1. 立即停止系统
2. 检查日志找原因
3. 降低仓位和杠杆
4. 重新回测验证
