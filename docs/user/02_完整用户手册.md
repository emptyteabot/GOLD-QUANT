## 系统概述

### 什么是AURUM？

AURUM是一个**AI驱动的黄金量化交易系统**，通过多个AI专家协同决策，实现24/7自动化交易。

### 核心架构

```
┌─────────────────────────────────────────┐
│           AURUM交易系统                  │
└─────────────────────────────────────────┘
                    │
    ┌───────────────┼───────────────┐
    ▼               ▼               ▼
┌─────────┐   ┌─────────┐   ┌─────────┐
│数据采集 │   │AI决策   │   │交易执行 │
│         │   │         │   │         │
│• OKX    │   │• 宏观   │   │• 下单   │
│• 行情   │   │• 技术   │   │• 风控   │
│• 指标   │   │• ML     │   │• 监控   │
└─────────┘   └─────────┘   └─────────┘
```

### 五大AI专家

1. **宏观分析师** - 分析美元、美债、VIX等宏观指标
2. **技术分析师** - 计算RSI、MACD、布林带等技术指标
3. **机器学习模型** - 使用RandomForest预测价格走势
4. **XAUT策略** - 基于黄金ETF相关性的策略
5. **RSI策略** - 专注超买超卖信号

### 工作流程

```
1. 数据采集 → 2. 多专家分析 → 3. 投票决策 → 4. 风险评估 → 5. 执行交易
```

## 策略系统

### 策略权重配置

编辑 `config.py`：

```python
# 策略权重（总和=1.0）
STRATEGY_WEIGHTS = {
    'macro': 0.20,      # 宏观分析 20%
    'technical': 0.20,  # 技术分析 20%
    'ml': 0.20,         # 机器学习 20%
    'xaut': 0.20,       # XAUT策略 20%
    'rsi': 0.20         # RSI策略 20%
}
```

### 各策略详解

#### 1. 宏观分析策略

**分析指标：**
- 美元指数（DXY）
- 美债收益率（10年期）
- VIX恐慌指数
- 黄金/白银比

**决策逻辑：**
```python
if 美元走弱 and 美债收益率下降 and VIX上升:
    信号 = "做多"
elif 美元走强 and 美债收益率上升 and VIX下降:
    信号 = "做空"
else:
    信号 = "观望"
```

#### 2. 技术分析策略

**使用指标：**
- RSI（相对强弱指数）
- MACD（指数平滑异同移动平均线）
- 布林带
- EMA（指数移动平均线）

**决策逻辑：**
```python
if RSI < 30 and MACD金叉 and 价格触及布林带下轨:
    信号 = "做多"
elif RSI > 70 and MACD死叉 and 价格触及布林带上轨:
    信号 = "做空"
```

#### 3. 机器学习策略

**模型：** RandomForest（随机森林）

**特征工程：**
- 30+个技术指标
- 价格变化率
- 成交量特征
- 时间特征

**训练流程：**
```python
1. 收集最近300根K线数据
2. 计算30+个特征
3. 训练RandomForest模型
4. 预测下一根K线涨跌概率
5. 概率>60%时产生信号
```

#### 4. XAUT策略

**原理：** 基于黄金ETF（XAUT）与现货黄金的相关性

**信号生成：**
```python
if XAUT溢价 > 阈值:
    信号 = "做多"  # XAUT需求强劲
elif XAUT折价 > 阈值:
    信号 = "做空"  # XAUT需求疲软
```

#### 5. RSI策略

**专注：** 超买超卖信号

**参数：**
- RSI周期：14
- 超买线：70
- 超卖线：30

**信号：**
```python
if RSI < 30:
    信号 = "做多"  # 超卖反弹
elif RSI > 70:
    信号 = "做空"  # 超买回调
```

### 自定义策略

#### 添加新策略

1. 创建策略文件 `my_strategy.py`：

```python
class MyStrategy:
    def __init__(self):
        self.name = "我的策略"

    def analyze(self, data):
        """
        分析数据并返回信号

        Returns:
            signal: 1=做多, -1=做空, 0=观望
            confidence: 0-1之间的置信度
        """
        # 你的策略逻辑
        if 条件A:
            return 1, 0.8  # 做多，置信度80%
        elif 条件B:
            return -1, 0.7  # 做空，置信度70%
        else:
            return 0, 0.5  # 观望
```

2. 注册策略到 `config.py`：

```python
from my_strategy import MyStrategy

STRATEGIES = {
    'macro': MacroAnalyst(),
    'technical': TechnicalAnalyst(),
    'ml': MLPredictor(),
    'xaut': XAUTStrategy(),
    'rsi': RSIStrategy(),
    'my_strategy': MyStrategy()  # 添加你的策略
}

STRATEGY_WEIGHTS = {
    'macro': 0.15,
    'technical': 0.15,
    'ml': 0.15,
    'xaut': 0.15,
    'rsi': 0.15,
    'my_strategy': 0.25  # 分配25%权重
}
```

## 风险管理

### 仓位管理

#### 动态仓位计算

```python
# 基础仓位
base_position = INITIAL_CAPITAL * MAX_POSITION_SIZE

# 根据信号强度调整
adjusted_position = base_position * signal_strength

# 根据置信度调整
final_position = adjusted_position * confidence

# 检查总仓位限制
if current_position + final_position > MAX_TOTAL_POSITION:
    final_position = MAX_TOTAL_POSITION - current_position
```

#### 仓位分级

| 信号强度 | 置信度 | 仓位比例 | 杠杆 |
|---------|--------|---------|------|
| 弱 (<30%) | 低 (<50%) | 10% | 2x |
| 中 (30-60%) | 中 (50-70%) | 20% | 3x |
| 强 (>60%) | 高 (>70%) | 30% | 5x |

### 杠杆管理

#### 动态杠杆

```python
# 基础杠杆
base_leverage = 5

# 根据置信度调整
if confidence > 0.8:
    leverage = base_leverage * 1.5  # 高置信度提高杠杆
elif confidence < 0.5:
    leverage = base_leverage * 0.5  # 低置信度降低杠杆
else:
    leverage = base_leverage

# 限制范围
leverage = max(MIN_LEVERAGE, min(leverage, MAX_LEVERAGE))
```

#### 杠杆建议

| 经验水平 | 回测 | 模拟盘 | 实盘 |
|---------|------|--------|------|
| 新手 | 5-10x | 3-5x | 1-2x |
| 进阶 | 10-20x | 5-10x | 2-5x |
| 专业 | 20x+ | 10-20x | 5-10x |

### 止损止盈

#### 固定止损

```python
# 入场价
entry_price = 2050.00

# 止损价（1.5%）
stop_loss = entry_price * (1 - 0.015) = 2019.25

# 止盈价（3%）
take_profit = entry_price * (1 + 0.03) = 2111.50
```

#### 移动止损

```python
# 盈利1%时，止损移到保本
if profit_pct > 0.01:
    stop_loss = entry_price

# 盈利2%时，锁定1%利润
if profit_pct > 0.02:
    stop_loss = entry_price * 1.01

# 盈利3%时，锁定2%利润
if profit_pct > 0.03:
    stop_loss = entry_price * 1.02
```

### 熔断机制

#### 单日亏损熔断

   - 进阶：$500-2000
   - 专业：$2000+

2. **逐步增加**
   - 运行1周无问题 → 增加50%
   - 运行1月稳定盈利 → 增加100%

   - 不要把所有资金放在一个策略
   - 考虑多品种分散（黄金+白银+原油）

#### 心态管理

1. **接受亏损**
   - 量化交易不是100%胜率
   - 关注长期收益，不纠结单笔亏损

2. **不要频繁调参**
   - 策略需要时间验证
   - 至少运行1个月再调整

3. **严格执行纪律**
   - 不要手动干预系统
   - 相信回测结果

## 故障排除

### 常见问题

#### 1. API连接失败

**症状：**
```
ERROR: Failed to connect to OKX API
```

**解决方案：**
```bash
# 检查网络
ping www.okx.com

# 检查API密钥
python test_api.py

# 检查防火墙
sudo ufw allow 443
```

#### 2. 回测数据不足

**症状：**
```
ERROR: Not enough data for backtest
```

**解决方案：**
```bash
# 下载历史数据
python download_data.py --days 90

# 检查数据完整性
python check_data.py
```

#### 3. 内存不足

**症状：**
```
MemoryError: Unable to allocate array
```

**解决方案：**
```bash
# 减少回测周期
BACKTEST_DAYS=30  # 改为30天

# 增加swap空间
sudo fallocate -l 4G /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
```

#### 4. 订单被拒绝

**症状：**
```
ERROR: Order rejected by exchange
```

**可能原因：**
- 余额不足
- 仓位超限
- 价格偏离太大
- API权限不足

**解决方案：**
```bash
# 检查余额
python check_balance.py

# 检查仓位
python check_positions.py

# 检查API权限
# 登录OKX → API管理 → 确认权限
```
