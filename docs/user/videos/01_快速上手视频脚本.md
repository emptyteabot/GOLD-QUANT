## 🎨 视频制作要点

### 画面要求

1. **清晰度**: 1080p或以上
2. **字幕**: 中文字幕，字体清晰
3. **配色**: 使用AURUM品牌色（金色#F59E0B）
4. **转场**: 简洁流畅，不要花哨

### 音频要求

1. **音质**: 清晰无杂音
2. **语速**: 适中，不要太快
3. **背景音乐**: 轻柔，不要盖过旁白
4. **音量**: 旁白和音乐平衡

### 剪辑要点

1. **节奏**: 紧凑但不急促
2. **重点**: 用字幕和箭头标注
3. **错误**: 剪掉卡顿和错误
4. **时长**: 严格控制在5分钟内
