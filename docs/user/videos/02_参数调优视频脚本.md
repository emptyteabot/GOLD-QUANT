### 第一部分：理解参数（0:30-2:00）

**画面**: 配置文件讲解

**旁白**:
```
首先，我们需要理解AURUM的核心参数。

打开config.py文件，主要有4类参数：

1. 信号阈值
   - MIN_SIGNAL_STRENGTH: 最小信号强度
   - MIN_CONFIDENCE: 最小置信度
   这两个参数控制交易频率

2. 仓位控制
   - MAX_POSITION_SIZE: 单次最大仓位
   - MAX_TOTAL_POSITION: 总仓位上限
   控制风险敞口

3. 杠杆设置
   - BASE_LEVERAGE: 基础杠杆倍数
   - MIN/MAX_LEVERAGE: 杠杆范围
   影响收益和风险

4. 止损止盈
   - STOP_LOSS_PCT: 止损比例
   - TAKE_PROFIT_PCT: 止盈比例
   保护利润

理解这些参数后，我们开始优化！
```

### 第三部分：优化方向1 - 提高收益（3:00-5:00）

**画面**: 修改参数并回测

