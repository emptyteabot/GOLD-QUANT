### 第四部分：配置系统（6:00-7:30）

**画面**: 编辑配置文件

**旁白**:
```
现在把API密钥配置到AURUM。

编辑 .env.trading 文件：

OKX_API_KEY=你的API_Key
OKX_SECRET_KEY=你的Secret_Key
OKX_PASSPHRASE=你的Passphrase

# 先使用模拟盘测试
OKX_SIMULATED=true

# 飞书通知（可选）
FEISHU_WEBHOOK_URL=你的webhook地址

保存文件。

然后编辑 .env：

MODE=live              # 切换到实盘模式
INITIAL_CAPITAL=100    # 初始资金$100
BASE_LEVERAGE=2        # 降低杠杆到2倍
MAX_POSITION_SIZE=0.2  # 降低仓位到20%

**画面**: 问题处理演示

```
实盘中可能遇到的问题：

问题1：亏损了怎么办？

不要慌！
1. 检查是否触发止损（正常）
2. 查看日志分析原因
3. 评估是否需要调整参数
4. 不要情绪化加仓

这是正常的，系统胜率40%

关注长期收益，不纠结单笔

问题2：系统没有交易？

可能原因：
1. 市场没有符合条件的信号
2. 信号阈值设置太高
3. 市场波动太小

解决：
- 耐心等待
- 不要频繁调参
- 相信系统判断

问题3：想手动干预？

⚠️ 不建议！
但如果必须：
1. 暂停系统
2. 手动操作
3. 记录原因
4. 重启系统

问题4：紧急情况？

如果遇到：
- 系统异常
- 网络断线
- 重大新闻

立即：
1. 停止系统
2. 手动平仓
3. 等待稳定
4. 重新评估

保持冷静，按流程处理。
