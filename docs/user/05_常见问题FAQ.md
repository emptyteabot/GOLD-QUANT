### Q14: 回测收益很高，实盘却亏损？

**A:** 常见问题，可能原因：

**1. 过拟合**
- 回测参数过度优化
- 只在特定时期表现好

**解决：**
- Walk-Forward验证
- 样本外测试
- 保持策略简单

**2. 滑点和手续费**
- 回测未考虑交易成本
- 实盘有滑点

**解决：**
- 回测时加入滑点
- 考虑手续费

**3. 市场环境变化**
- 回测时期和实盘不同
- 策略不适应新环境

**解决：**
- 定期重新回测
- 调整策略参数

### Q15: 如何解读回测报告？

**A:**

**关键指标：**

| 指标 | 含义 | 好坏标准 |
|------|------|----------|
| 收益率 | 赚了多少 | >0%为盈利 |
| 最大回撤 | 最大亏损 | <10%为优秀 |
| 夏普比率 | 风险调整后收益 | >1为良好 |
| 胜率 | 盈利交易占比 | >40%为合格 |
| 盈亏比 | 平均盈利/平均亏损 | >2为优秀 |

**示例分析：**
```
收益率: +1.92%     ✅ 盈利
最大回撤: 1.64%    ✅ 风险低
夏普比率: 1.85     ✅ 良好
胜率: 40%          ✅ 合格
盈亏比: 2.72       ✅ 优秀

结论：稳健的策略
```

## 风险管理

### Q26: 最大回撤是什么意思？

**A:** 从最高点到最低点的最大跌幅

**示例：**
```
初始资金: $1000
最高达到: $1100 (盈利10%)
然后跌到: $1050
最大回撤: (1100-1050)/1100 = 4.55%
```

**标准：**
- <5%：优秀
- 5-10%：良好
- 10-15%：可接受
- >15%：需要优化

---

### Q39: 如何计算实际收益率？

**A:**

```python
# 考虑所有成本
initial_capital = 1000      # 初始资金
final_capital = 1050        # 最终资金
trading_fees = 5            # 交易手续费
withdrawal_fees = 2         # 提现手续费

# 实际收益
actual_profit = final_capital - initial_capital - trading_fees - withdrawal_fees
# = 1050 - 1000 - 5 - 2 = $43

# 实际收益率
actual_return = actual_profit / initial_capital
# = 43 / 1000 = 4.3%
```

---

### Q40: 复利如何计算？

**A:**

```python
# 复利公式
# FV = PV * (1 + r)^n

# 示例：月收益2%，投资1年
initial = 1000
monthly_return = 0.02
months = 12

final = initial * (1 + monthly_return) ** months
# = 1000 * 1.02^12 = $1,268.24

# 对比单利
simple = initial * (1 + monthly_return * months)
# = 1000 * 1.24 = $1,240.00

# 复利多赚
difference = final - simple
# = $28.24
```
