## 1. 数据库架构概览

### 1.1 数据库选型

| 数据库 | 用途 | 理由 |
|--------|------|------|
| **PostgreSQL 15** | 业务数据 | ACID保证、成熟稳定、丰富的数据类型 |
| **TimescaleDB** | 时序数据 | PostgreSQL扩展、SQL友好、高性能时序查询 |
| **Redis 7** | 缓存 | 高性能、丰富数据结构、持久化支持 |

### 1.2 数据分层

```
┌─────────────────────────────────────────┐
│         应用层 (FastAPI)                 │
└─────────────────────────────────────────┘
                    │
        ┌───────────┼───────────┐
        ▼           ▼           ▼
┌──────────┐ ┌──────────┐ ┌──────────┐
│PostgreSQL│ │TimescaleDB│ │  Redis   │
│(业务数据)│ │(时序数据) │ │ (缓存)   │
└──────────┘ └──────────┘ └──────────┘
```

## 2. PostgreSQL数据库设计

### 2.1 用户表 (users)

```sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    full_name VARCHAR(100),
    phone VARCHAR(20),
    status VARCHAR(20) DEFAULT 'active', -- active, suspended, deleted
    role VARCHAR(20) DEFAULT 'user', -- user, admin, vip
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW(),
    last_login_at TIMESTAMP,
    CONSTRAINT email_format CHECK (email ~* '^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}$')
);

-- 索引
CREATE INDEX idx_users_email ON users(email);
CREATE INDEX idx_users_username ON users(username);
CREATE INDEX idx_users_status ON users(status);
CREATE INDEX idx_users_created_at ON users(created_at DESC);

-- 注释
COMMENT ON TABLE users IS '用户基本信息表';
COMMENT ON COLUMN users.status IS '用户状态: active-正常, suspended-暂停, deleted-已删除';
COMMENT ON COLUMN users.role IS '用户角色: user-普通用户, admin-管理员, vip-VIP用户';
```

### 2.2 API密钥表 (api_keys)

```sql
CREATE TABLE api_keys (

    passphrase_encrypted TEXT,
    permissions JSONB DEFAULT '{"trade": true, "read": true}',
    status VARCHAR(20) DEFAULT 'active', -- active, expired, revoked
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW(),
    last_used_at TIMESTAMP,
    expires_at TIMESTAMP,
    CONSTRAINT unique_user_exchange UNIQUE(user_id, exchange)
);

-- 索引
CREATE INDEX idx_api_keys_user_id ON api_keys(user_id);
CREATE INDEX idx_api_keys_exchange ON api_keys(exchange);
CREATE INDEX idx_api_keys_status ON api_keys(status);

-- 注释
COMMENT ON TABLE api_keys IS 'API密钥表（加密存储）';
COMMENT ON COLUMN api_keys.api_key_encrypted IS 'AES-256加密的API密钥';
COMMENT ON COLUMN api_keys.permissions IS 'API权限配置（JSON格式）';
```

### 2.3 策略表 (strategies)

```sql
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW(),
    started_at TIMESTAMP,
    stopped_at TIMESTAMP,
    CONSTRAINT check_leverage CHECK (max_leverage >= 1 AND max_leverage <= 20),
    CONSTRAINT check_position_ratio CHECK (max_position_ratio > 0 AND max_position_ratio <= 1)
);

-- 索引
CREATE INDEX idx_strategies_user_id ON strategies(user_id);
CREATE INDEX idx_strategies_status ON strategies(status);
CREATE INDEX idx_strategies_symbol ON strategies(symbol);
CREATE INDEX idx_strategies_created_at ON strategies(created_at DESC);

-- 注释
COMMENT ON TABLE strategies IS '交易策略配置表';
COMMENT ON COLUMN strategies.config IS '策略参数配置（JSON格式）';
COMMENT ON COLUMN strategies.max_leverage IS '最大杠杆倍数（1-20倍）';
```

## 3. TimescaleDB时序数据设计

### 3.1 K线数据表 (klines)

```sql
CREATE TABLE klines (
    time TIMESTAMPTZ NOT NULL,
    symbol VARCHAR(20) NOT NULL,
    timeframe VARCHAR(10) NOT NULL, -- 1m, 5m, 15m, 1h, 4h, 1d
    open NUMERIC(20, 8) NOT NULL,
    high NUMERIC(20, 8) NOT NULL,
    low NUMERIC(20, 8) NOT NULL,
    close NUMERIC(20, 8) NOT NULL,
    volume NUMERIC(20, 8) NOT NULL,
    quote_volume NUMERIC(20, 8),
    trades_count INTEGER,
    PRIMARY KEY (time, symbol, timeframe)
);

-- 创建超表（TimescaleDB特性）
SELECT create_hypertable('klines', 'time',
    chunk_time_interval => INTERVAL '7 days',
    if_not_exists => TRUE
);

-- 创建索引
CREATE INDEX idx_klines_symbol_timeframe ON klines(symbol, timeframe, time DESC);

-- 数据保留策略（保留1年数据）
SELECT add_retention_policy('klines', INTERVAL '1 year');

-- 压缩策略（7天后压缩）
ALTER TABLE klines SET (
    timescaledb.compress,
    timescaledb.compress_segmentby = 'symbol, timeframe'
);
SELECT add_compression_policy('klines', INTERVAL '7 days');

-- 注释
COMMENT ON TABLE klines IS 'K线数据表（时序数据）';
```

## 4. Redis缓存设计

### 4.1 缓存键命名规范

```
格式: {namespace}:{entity}:{id}:{field}
示例:
- aurum:user:123:profile
- aurum:strategy:456:config
- aurum:price:XAU-USDT-SWAP:latest
```

### 4.2 缓存数据结构

#### 4.2.1 用户会话 (String)
```redis
# 键: aurum:session:{user_id}
# 值: JWT Token
# 过期: 24小时
SET aurum:session:123 "eyJhbGc..." EX 86400
```

#### 4.2.2 实时价格 (Hash)
```redis
# 键: aurum:price:{symbol}
# 字段: last, bid, ask, volume, timestamp
HSET aurum:price:XAU-USDT-SWAP last 4819.20
HSET aurum:price:XAU-USDT-SWAP bid 4819.10
HSET aurum:price:XAU-USDT-SWAP ask 4819.30
EXPIRE aurum:price:XAU-USDT-SWAP 60
```

#### 4.2.3 交易信号队列 (List)
```redis
# 键: aurum:signals:{symbol}
# 值: JSON格式的信号数据
LPUSH aurum:signals:XAU-USDT-SWAP '{"signal": 0.5, "confidence": 0.7, ...}'
LTRIM aurum:signals:XAU-USDT-SWAP 0 99  # 保留最近100条
```

#### 4.2.4 用户持仓缓存 (Hash)
```redis
# 键: aurum:position:{user_id}:{symbol}
# 字段: quantity, avg_price, pnl, leverage
HSET aurum:position:123:XAU-USDT-SWAP quantity 408
HSET aurum:position:123:XAU-USDT-SWAP avg_price 4754.90
EXPIRE aurum:position:123:XAU-USDT-SWAP 300
```

#### 4.2.5 API限流 (String)
```redis
# 键: aurum:ratelimit:{user_id}:{endpoint}
# 值: 请求次数
INCR aurum:ratelimit:123:/api/v1/orders
EXPIRE aurum:ratelimit:123:/api/v1/orders 60  # 1分钟窗口
```

#### 4.2.6 策略状态 (Hash)
```redis
# 键: aurum:strategy:{strategy_id}:status
# 字段: status, last_signal, last_trade, equity
HSET aurum:strategy:456:status status "running"
HSET aurum:strategy:456:status last_signal "0.5"
HSET aurum:strategy:456:status equity "1253.37"
```

```sql
CREATE EXTENSION IF NOT EXISTS "pgcrypto";

-- 创建所有表（按依赖顺序）
-- 1. 用户表

-- 2. API密钥表
CREATE TABLE api_keys (...);

-- 3. 策略表

-- 4. 订单表
CREATE TABLE orders (...);

-- 5. 持仓表
CREATE TABLE positions (...);

-- 6. 账户余额表
CREATE TABLE account_balances (...);

-- 创建触发器：自动更新updated_at
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = NOW();
    RETURN NEW;
END;
$$ language 'plpgsql';

CREATE TRIGGER update_users_updated_at BEFORE UPDATE ON users
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

CREATE TRIGGER update_api_keys_updated_at BEFORE UPDATE ON api_keys
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

CREATE TRIGGER update_strategies_updated_at BEFORE UPDATE ON strategies
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

-- 插入测试数据
```

## 7. 性能优化

### 7.1 索引优化

```sql
-- 复合索引（常用查询组合）
CREATE INDEX idx_orders_user_symbol_time
    ON orders(user_id, symbol, created_at DESC);

CREATE INDEX idx_trades_strategy_time
    ON trades(strategy_id, time DESC)
    WHERE pnl IS NOT NULL;

-- 部分索引（只索引活跃数据）
CREATE INDEX idx_active_strategies
    ON strategies(user_id, status)
    WHERE status = 'running';
```

### 7.2 查询优化

```sql
-- 使用物化视图（预计算常用统计）
CREATE MATERIALIZED VIEW user_statistics AS
SELECT
    user_id,
    COUNT(*) as total_trades,
    SUM(pnl) as total_pnl,
    AVG(pnl) as avg_pnl,
    MAX(created_at) as last_trade_time
FROM trades
GROUP BY user_id;

-- 创建索引
CREATE INDEX idx_user_statistics_user_id
    ON user_statistics(user_id);

-- 定时刷新（每小时）
CREATE OR REPLACE FUNCTION refresh_user_statistics()
RETURNS void AS $$
BEGIN
    REFRESH MATERIALIZED VIEW CONCURRENTLY user_statistics;
END;
$$ LANGUAGE plpgsql;
```

## 9. 安全措施

### 9.1 数据加密

```sql
-- API密钥加密存储
CREATE OR REPLACE FUNCTION encrypt_api_key(plain_text TEXT)
RETURNS TEXT AS $$
BEGIN
    RETURN encode(
        pgp_sym_encrypt(plain_text, current_setting('app.encryption_key')),
        'base64'
    );
END;
$$ LANGUAGE plpgsql;

-- API密钥解密
CREATE OR REPLACE FUNCTION decrypt_api_key(encrypted_text TEXT)
RETURNS TEXT AS $$
BEGIN
    RETURN pgp_sym_decrypt(
        decode(encrypted_text, 'base64'),
        current_setting('app.encryption_key')
    );
END;
$$ LANGUAGE plpgsql;
```

### 9.2 访问控制
