- 自动止损止盈

**Q: 为什么没有交易信号？**

**Q: 为什么频繁止损？**

**Q: 可以调整参数吗？**
A: 可以，编辑 `scalping_engine.py` 中的参数。

**Q: 如何切换到实盘？**
